# むしむし！ びよーん！

4歳児向けのモバイル Web ゲームです。iPhone / iPad のブラウザ（モバイル Safari 相当）で、
**文字を一切読まずに**、豆をふくらませ、むし、しゅっとかけ、パックに詰め、あたためて、
混ぜて、最後に **びよーん** と糸を引くまでを一周遊べます。

> ネタバレ注意 — 以下は大人向けの説明です。
> 作っているのは **納豆** ですが、ゲーム中は最後の糸引きまで完成品名もパッケージも出しません。
> 「あ、これ知ってる！」が立ち上がる瞬間を守るため、画面には一切の文字がありません。

## 遊びかた（操作は全部一本指）

| 工程 | 操作 | 起きること |
| --- | --- | --- |
| 1 みずにいれる | どこかを **タップ** | 水が注がれ、かたい豆がふくらむ |
| 2 むす | **タップ** → 連打 | ふたが閉まり、もくもく湯気。連打すると火力が上がる |
| 3 しゅっ | **タップ / 長押し** ×3 | 霧が飛び、豆がきらっとする |
| 4 パックへ | **タップ** ×3 | 豆がぽとぽと落ちて、ますにきちんと並ぶ |
| 5 はっこう | ダイヤルを **ぐるぐる** | 昼夜が流れ、時計が回り、箱があたたまる |
| 6 あける | ふたを **上へドラッグ** | 中はまだ「ただの豆」に見える |
| 7 まぜる | 棒を **ぐるぐる** | 混ぜるほど白くぬめり、糸が増える |
| 8 びよーん | そのまま **上へドラッグ** | 白い糸がびよーんと伸びる（何度でも） |
| 9 できあがり | **タップ** ×3 | ごはん・たれ・からし。最後に納豆ごはんが完成 |

- 制限時間なし・ゲームオーバーなし・スコアなし。
- 2 秒ほど手が止まると、次にさわる物が揺れて指マークが出ます。
- 操作がずれても進みます（円を描けなくても、なぞるだけで混ざる／蛇口を外してタップしても水は出る）。
- 右下の丸い矢印を **1 秒長押し** すると最初に戻ります（誤操作しにくいよう長押しにしてあります）。
- 完成画面の 2 つのボタンは「もういちど びよーん」と「はじめから」です。

## 起動方法

静的ファイルだけなので、任意の HTTP サーバで配信すれば動きます（ES Modules のため
`file://` 直開きは不可）。

```bash
npm start              # http://127.0.0.1:8123/ （npx http-server）
# もしくは
python3 -m http.server 8123
```

iPhone / iPad で開く場合は、同じ Wi-Fi 上から `http://<PCのIP>:8123/` を Safari で開き、
必要なら「ホーム画面に追加」でフルスクリーン表示にしてください。

### URL パラメータ

| パラメータ | 用途 |
| --- | --- |
| `?scene=finale` | 任意の工程から開始（`soak` `steam` `spray` `pack` `ferment` `finale` `reveal`） |
| `?fast=1` | 軽量モード（DPR 1・パーティクル削減）。E2E 用 |
| `?seed=7` | 乱数シード固定 |

## 素材（焼き込み）

豆と米は、実行時に描いているのではなく **オフラインで焼いた PNG** です。

```bash
npm start          # 別ターミナルでサーバを立てておく
npm run bake       # assets/*.png を再生成（数十秒）
```

`tools/bake.mjs` がヘッドレス Chromium をレンダラーとして起動し、1 枚あたり
数秒かけて per-pixel で **高さ場 → 法線 → 3灯ライティング → 表面下散乱 →
濡れコート → フレネル → AO** を計算します。実行時は `drawImage` するだけです。

- 豆は工程 5 種 × 個体 8 種。**向きは形だけを焼き込み時に回し、光は画面に固定**
  しています（スプライトを実行時に回すと、焼き込んだ光まで回って嘘になる）。
- 納豆の「粘り」は `src/natto.js` が担当します。豆の円と近接ペアの帯を合成した
  メタボールで塊を作り、接触影・照り・泡・糸・膜・宙に立つ糸を重ねます。
- 材質だけを確認するページ: `material.html`（`npm run bench` で画像化）

## 構成

```
index.html          画面いっぱいのキャンバス 1 枚だけ
styles.css          iOS 向けの拡大・ゴムバンド抑止
src/
  main.js           起動とテスト用フック（window.__natto）
  game.js           シーン管理・入力・遷移・進行ドット
  util.js           数学 / 決定的乱数 / スプライト
  audio.js          効果音（WebAudio で合成。音声ファイルなし）
  fx.js             パーティクル（湯気・きらきら・霧・しずく・泡）
  art.js            器・道具・背景の描画
  natto.js          納豆の材質（塊・接触影・照り・泡・糸・膜）と焼き込み素材
assets/             焼き込み済みスプライト（PNG, 約 2.4MB）
tools/              焼き込みパイプライン（bake.mjs / gen/*.js）
  scenes/           title / soak / steam / spray / pack / ferment / finale / reveal
tests/play.mjs      縦横それぞれで一周プレイする自動確認
```

- ライブラリ・ビルド・アセットは一切なし。Canvas 2D のみ。
- 3D は使わず、**シーン制御型の 2.5D**。自由カメラなし。
- 糸は物理シミュレーションではなく、**先細りリボン＋たるみ＋ゆらぎ**で「偽装」しています。
  粘りは `sticky`（0→1）というひとつの数値だけで、色・膜・糸の本数・切れにくさ・
  音の高さ・持ち上げたときの抵抗をまとめて動かしています。
- 「開ける → 混ぜる → 持ち上げる」は **1 シーン**にまとめ、カットを割らずに
  接写（ズーム 1.2）→ 引き（ズーム 0.84）へ連続的に寄り引きします。

## 自動確認

```bash
npm test        # 縦 (390x844) / 横 (844x390) / iPad (1024x768) で一周
```

各工程の状態（水位・蒸気ゲージ・粘り・糸の本数・持ち上げ量など）を実際に操作して検証し、
`/tmp/natto-shots/` にスクリーンショットを残します。最後に画面を回転させて破綻しないことも見ます。
