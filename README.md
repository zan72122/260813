# らでん きらきら

4歳児向けの iPhone / iPad モバイルWebゲーム。
日本の伝統工芸「螺鈿（らでん）」を題材にした、一指で遊べる Beauty Reveal ゲームです。

> 貝の虹を 黒いものの中に入れて、みがいて出す。

## 遊びかた（ことばはいりません）

1. 棚から黒い漆器（お皿・小箱・かんざし）をひとつ選ぶ
2. 虹色に光る貝のかけらを、指で模様のくぼみへ運ぶ（近づくと磁石のように吸い付く）
3. 職人さんが黒い塗りをかけると……貝が見えなくなる。「どこへ行ったの？」
4. 指で大きくこすって磨くと、指の跡から虹色の貝がスーッと現れる
5. ぜんぶ磨けたら完成。光の下で指で傾けると、貝の色が青・緑・紫・ピンク・金色へ揺らめく

- 点数なし・失敗なし・時間制限なし・文章なし
- 好きな順番で磨けます。磨き残しはきらきらとお手本の手がそっと教えてくれます
- 完成後は何度でも傾けて鑑賞でき、「もう一回」ボタンでまた塗って磨き直せます

模様は 蝶・花・月と波・魚・星空 の5種類。

## 実行方法

ビルド不要・依存ゼロの静的サイトです。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad の Safari で開く
```

GitHub Pages でそのまま公開できます（リポジトリの Pages 設定でこのブランチを指定するだけ）。

## 技術メモ

- 純 WebGL 1（ライブラリなし）。iOS Safari 互換を最優先
- **貝片**: view-dependent な軽量イリデッセンス・シェーダ（fbm ノイズ＋余弦パレット＋傾きで動くハイライト帯とグリント）
- **黒漆**: SDF ベースの器形状に、磨き量で変化する clearcoat（艶・環境反射・フレネル・ハイライト）
- **磨き**: 2D Canvas に描くマスクテクスチャによる progressive reveal。指の 26px 上をブラシ中心にして、現れる境界が指で隠れないようにしています
- 塗膜下の貝片は、漆側とまったく同じ `coatColor()` を共有することでピクセル一致で「消え」ます
- 音はすべて WebAudio による手続き合成（磨き音は指の速さと、その場所の磨き上がり具合で明るく変化）
- 進捗は 40×40 グリッドで追跡し、9割磨けたら残りを自動で仕上げて全面ハイライトが走ります

## 検証

Playwright（Chromium、iPhone 縦 390×844 / iPhone 横 844×390 / iPad 1024×768、タッチ有効）で
「選ぶ→置く→塗られる→磨く→完成→傾ける」の全工程を全5模様で自動プレイし、
JSエラーゼロ・全状態遷移を確認済み。
