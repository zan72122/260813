# のびのび！しゃらら！ そうめんこうじょう

4さいからの、ゆびいっぽんで あそべる モバイルWebゲーム。
文字なし・制限時間なし・失敗なし。iPhone / iPad のブラウザでそのまま動きます。

> **ネタバレ注意（おとなの方へ）**
> このゲームは「最初はなんだか分からない白いもの」が、最後に「そうめん」だと
> 分かる構造になっています。子どもに渡す前に結末を教えないでください。

## あそびかた

画面をさわるだけです。次にさわる場所は、まよっていると自動でゆれて教えます。

1. しろい かたまりを あつめる
2. ひっぱって ながくする
3. ぼうに かける
4. もういちど ひっぱって ほそくする
5. ぼうを とおして ならべる（しゃらら）
6. かぜで かわかす
7. おなじ ながさに きる
8. たばねる
9. …できあがり！

## 動かす

ビルド不要・依存ゼロ。静的ファイルを配信するだけです。

```bash
npm start          # http://localhost:4173 で配信
```

iPhone / iPad で遊ぶときは、同じ Wi-Fi 上のPCの LAN IP に
`http://<PCのIP>:4173/` でアクセスしてください。
GitHub Pages などの静的ホスティングにそのまま置けます。

## テスト

```bash
npm test                      # Chromium で iPhone縦 / iPad横 の 2 プロファイル
E2E_FAST=1 npm test           # 低解像度で高速に
node tools/shots.mjs OUT_DIR portrait   # 各ステージのスクリーンショット（開発用）
```

テストは自動プレイフックで一周を通し、実際のタッチイベントでも
入力経路を検証します。

## 設計

| ファイル | 役割 |
| --- | --- |
| `js/main.js` | 起動・メインループ・画面UI・自動プレイ |
| `js/stages.js` | 9 ステージのゲームロジック（1本の遊びのループ） |
| `js/world.js` | 共有ステートと麺線モデル・レイアウト |
| `js/art.js` | 描画（形は手続き的、表面は焼き込み済みテクスチャ） |
| `js/textures.js` | 焼き込みタイルの読み込みとワールド固定パターン |
| `js/layer.js` | 静的な大面積サーフェスのキャッシュ |
| `js/light.js` | 全体で共有する単一光源 |
| `js/scene.js` | キャンバス・カメラ・単一指ポインタ |
| `js/audio.js` | WebAudio の効果音（合成、ファイルなし） |
| `js/fx.js` | パーティクルとリング |
| `js/util.js` | 数学・イージング・色 |

### 4歳児向けに守っていること

- **一指のみ。** 2本目以降のタッチは無視するので、手のひらが当たっても
  ドラッグが乗っ取られません。
- **失敗なし。** 引っ張った長さや乾き具合は減りません。当たり判定は
  すべて広めで、近ければ吸着して成功します。
- **文字なし。** UI は絵だけ（スピーカーアイコンと「もういちど」の矢印）。
- **時間制限なし。** 2.4 秒まよっていると、次にさわる場所が指アイコンと
  波紋でゆれて誘導します。
- **カメラは自動。** 導入 → 延ばし → 整列 → 乾燥 → 束 → リビール の順に
  ゲーム側が寄り引きします。プレイヤーはカメラを操作しません。

### 素材（実写ベース）

背景と主役の表面は、CC0 の実写マテリアル（ambientCG）から**ビルド時に**生成した
タイルです。要点は「ライティングをビルド時に解いて焼き込む」こと:

```bash
node tools/ingest-textures.mjs <展開したzipのディレクトリ>   # 素材の正規化
node tools/bake-textures.mjs                                  # 陰影を焼き込む
```

`tools/bake-textures.mjs` は法線・AO・粗さマップから 1 光源のライティングを解き、
色と合成して 1 枚の「すでに照らされた」画像にします。**実行時はただのパターン
塗りなので、単色塗りと同じコストのまま表面の凹凸が光ります。** 光源方向は
`js/light.js` と共有していて、手描きのハイライトや接地影もすべて同じ方向を向きます。

出力は `assets/baked/`（合計 84KB）。元素材は `assets/source/`（592KB、CC0）。

### 大面積サーフェスのキャッシュ

繰り返しパターンは 1 ピクセルごとに再サンプリングが必要で、壁・床・食卓のような
全画面サーフェスでは無視できません。これらはカメラが動いたときだけ変わるので、
`js/layer.js` がオフスクリーンに 1 度描いて以後は等倍で転送します。カメラが動いて
いる間はキャッシュせず直接描くので、遷移中も「描画＋転送」の二重払いになりません。

### 麺線の表現

物理シミュレーションはしません。麺 1 本は十数個のパラメータで、
レイアウト関数が 22 点のポリラインを生成します。ステージ間の変形
（垂れ下がり → 板の上 → 束）は 2 つのレイアウトの線形補間だけです。
44 本でもモバイルで軽く動きます。

### パフォーマンス

フレームが伸びると描画解像度を自動で下げます（`setRenderScale`、
1.0 → 0.55 まで、ヒステリシス付き）。古い iPad は CPU より先に
フィルレートが頭打ちになるため、コマ落ちさせるより画素を減らします。

## ライセンス

このリポジトリのコードとアートはすべて自作です。外部アセットはありません。
