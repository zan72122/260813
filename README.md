# ぺちゃんこフィールド

4歳向けの iPhone / iPad モバイルWeb 3Dゲーム。

プレイヤーは、物体の「厚さ」を変えられる不思議なフィールド。
大きいものをぺちゃんこにして、すきまを通す — それだけのゲームです。

## 遊び方（一本指だけ）

1. 指を置くと、光る円盤（フィールド）が指についてくる
2. 物の上でじっと押さえると、ギューッ…と潰れて紙のようにペラペラになる
3. そのまま引きずって、ドアの下・細いスリット・格子の間をスルッと通す
4. 向こう側で指を離すと「ポン！」と元の形に戻る

文字・得点・失敗・制限時間はありません。
関係ない物（木やお花）を潰しても楽しい変形が見られます。

## ステージ

| ステージ | 隙間 | 物体 | フィールド |
|---|---|---|---|
| おへや | ドアの下 (高め) | クッション・はこ・ボール | 小 |
| おにわ | 壁のスリット (中) | いす・くまさん | 中 |
| こうえん | 格子の下 (低い) | じてんしゃ・ぞうさん | 大 |

全部届けるとフィールドが成長して、より大きな物を潰せるようになります。

## 実行

```
npm install
npm start        # http://localhost:8199
```

静的サイトなので、リポジトリをそのまま任意の静的ホスティングに置いても動きます
（three.js は `vendor/` に同梱済み。ビルド不要）。

## テスト

```
npx playwright test
```

`?e2e=1` を付けると論理時間を `window.__PF.tick(ms)` で決定的に進められる
テスト用フックが有効になります（描画は通常どおり）。

## 実装メモ

- three.js / WebGL。変形は soft-body ではなく、パーツ単位の非一様スケール
  （高さ縮小・下ほど横に広がる・バネでプルンと揺れる）をデータ駆動で全物体に使い回し
- 影はブロブ影、効果音は WebAudio 合成（外部アセットなし）
- カメラは自動制御のみ: 通常は 3/4 俯瞰、隙間へ近づくと低いななめ視点、
  通過後は引きで「ポン！」を見せる
- 縦・横画面両対応、DPR上限2、タッチは指の少し上をつまむ（指で対象が隠れない）
