# あまいひみつ

4歳児向け iPhone / iPad モバイル Web ゲーム。
**最後の最後まで「作っているものの正体」を隠す**プリン工房です。

遊ぶ側は「何だろう、この茶色い液体と黄色い液体」から始まり、
型を持ち上げた瞬間に初めて「プリンだ！」に到達します。

```
npm start          # http://localhost:4173 で配信
npm test           # Chromium で 1 周プレイして検証（縦画面）
npm run test:land  # 同上（横画面）
npm run test:hero  # 「型を抜く 3 秒」だけをコマ撮り
```

Playwright がグローバル導入の環境では `NODE_PATH=/opt/node22/lib/node_modules` を付けてください。
ビルド手順はありません。静的ファイルをそのまま配信すれば動きます。

## 認知体験の設計

| # | 工程 | 動詞 | 操作 | 視覚変化 |
|---|------|------|------|----------|
| 1 | `caramelize` | あたためる | 大きなレバーを下へドラッグ | 透明な砂糖液 → 淡い金 → 琥珀色 |
| 2 | `pour-caramel` | そそぐ | 鍋を傾けるドラッグ | 型の底に琥珀の層がたまる |
| 3 | `mix` | まぜる | 円運動 | 白い筋が消えてなめらかな黄色に |
| 4 | `pour-custard` | そそぐ | ボウルを傾けるドラッグ | 茶色の上に黄色が重なり二層になる |
| 5 | `steam` | あたためる | 蓋を下へドラッグ | 湯気が噴き、液面が固まる |
| 6 | `chill` | ひやす | 冷たい扉を横へドラッグ | 全体が青くなり霜がつく |
| 7 | `plate-on` | かぶせる | 皿を下へドラッグ | 白い皿が型にかぶさる（なぜ？） |
| 8 | `flip` | ひっくりかえす | 大きな弧のスワイプ | 皿と型が一緒に 180 度回る |
| 9-11 | `demold` | かたをぬく | ゆっくり上へドラッグ | 型が上がる → ぷるん → カラメルが流れる |
| 12 | `reveal` | ―（自動） | ― | カメラが引いて全体が見える |

工程 9・10・11 は「1 つの操作から連続して起きる 1 つの体験」なので
1 モジュール（`demold`）にまとめ、その内部を
**引き上げ → 離型 → 減衰振動 → カラメル流下**の 4 拍で構成しています。

### 正体を隠す仕掛け

- ゲーム中に**文字は一切描画しません**（`fillText` を 1 度も呼びません）。
  誘導は「手のアイコン」と「破線の道すじ」だけです。
- タイトル画面に出るのは、鍋・銀色の型・ボウルの 3 つだけ。
  完成品・シルエット・パッケージは登場しません。
- ブラウザのタブに出るタイトルも「あまいひみつ」で、正体を明かしません。
- 型は不透明な銀色なので、工程 1〜8 では中身の形が一切見えません。
- 黄色い塊としての姿が初めて現れるのは工程 9（全 10 モジュール中 9 番目 ≒ **85% 地点**）。
  それも下から少しずつで、全体像が見えるのは工程 11〜12 です。

### リプレイ磁石（最優先で磨いた 3 秒）

「型を持ち上げる直前 → 外れる → ぷるん → カラメルが流れる」に予算を集中しています。

- 引き上げの終盤は**わざと抵抗**を作り、プリンがわずかに伸びる（`stick`）。
- しきい値を越えると離型。カメラが軽く揺れ、`purun` 音が鳴る。
- ばね（ζ≈0.4 の減衰振動）で**つぶれて戻る**（`squash`）。
- 進行波の頂点オフセットで**横に揺れる**（`wobble`、上ほど大きい）。
- 揺れが収まりはじめる頃にカラメルが頂上から側面へ**遅れて流れ落ちる**。

完成画面には大きな「もう一度型をぬく」ボタンがあり、
押すと**型がプリンにかぶさりながら降りてきて**、すぐにもう一度引き抜けます。

## 4歳児向けの入力設計

- **画面のどこを触っても操作できます。** 対象物を正確にタップする必要はありません。
  これが「指がプリンやカラメルを隠さない」ための一番強い対策でもあります。
- **進捗は減りません。** 逆方向の手ぶれや往復は無視され、正しい向きの成分だけが加算されます。
- **斜めでも通ります。** 直交成分も 12% だけ加点されます。
- **円運動は指の移動平均を中心に判定します。** 画面のどこで、どんな大きさで回しても成立し、
  ぐるぐる回せなくても「ゴシゴシ往復」で進みます。
- **反転は 78% まで回せば自動で決まります。**
- **必要なドラッグ量は画面サイズから計算します**（`vDist` / `hDist`）。
  iPhone 縦でも iPad 横でも「大きく 1〜1.5 ストローク」で完了します。
- **16 秒（型抜きは 26 秒）触られないと自動で進みます。** 詰まって泣くことはありません。
- 制限時間・採点・ゲームオーバー・失敗はありません。

## 技術的な選択

### レンダラは Canvas2D

要件は「WebGL2 相当でも看板演出が成立する設計」でした。
そこで **WebGL / WebGPU を一切使わず Canvas2D だけで完結**させています。
WebGL2 が使えない端末・ドライバでも表示が壊れず、
Hero Material 3 種（琥珀色で半透明なカラメル / なめらかな黄色いプリン / 光沢のある銀色型）を
グラデーションと合成モードで表現できるためです。
WebGPU 前提の追加品質レイヤーは載せていません。

### 流体・soft-body は使っていません

- **カラメル**: 頂点を並べたリボン状のポリゴンです。円錐の「手前側の面」を
  方位角から解析的に求めて伝わせているため、側面に貼りついて見えます。
- **プリンの揺れ**: バネ 1 個（squash）＋進行波の頂点オフセット（wobble）だけです。
  頂点シェーダでやることを JS の 16 スライスでやっている、と考えてください。
- **注ぐ流れ**: 注ぎ口から着地点までのテーパー付きリボン。着地点は
  型の中の現在の液面（`moldPoolPoint`）に追従します。

### カメラ

自由操作はできません。各工程が「**ワールド上のこの箱を必ず画面に収めろ**」という
枠（`{x, y, w, h, k, anchor}`）を宣言し、`View` が縦横のアスペクトから
倍率を自動計算します。これで iPhone 縦・iPad 横のどちらでも同じ演出が成立します。

`k` は仰角の sin（0 = 真横、1 = 真上）で、楕円のつぶれ具合と高さの圧縮率を決めます。

| 工程 | 枠 | 仰角 `k` | ねらい |
|------|----|---------|--------|
| 注ぐ | 236×132 | 0.52 | 接写。型の中がのぞける角度 |
| 反転 | 276×180 | 0.20 | 中景。ほぼ真横なので回転が読める |
| 型ぬき | 168×152 | 0.34 | 低めの 3/4 クローズアップ（皿は切れてよい） |
| 完成 | 268×132〜152 | 0.42 | 少し引いて全体を見せる |

### 指が隠さないための配置

- ジェスチャは画面全体で受けるので、被写体に触る必要がありません。
- 誘導（手と矢印）は縦画面なら下 16%、横画面なら右 20% の「安全地帯」に出ます。
- 完成画面のボタンは縦なら下中央、横なら右下。横画面では被写体を左へ寄せて避けます。

### パフォーマンス

- 壁・光・周辺減光はオフスクリーンに焼き、毎フレームは `drawImage` 2 回で済ませています。
- 描画ピクセル数に上限（約 260 万）を設け、iPad Pro 級でも塗り面積が膨らみません。
- `?fast=1` で devicePixelRatio を 1 に固定します（E2E 用）。

計測は SwiftShader（CPU ラスタライズ）なので実機の数字ではありませんが、
上記の対策で iPad 相当の解像度が 18fps → 40fps になりました。
**FPS・アニメーションの滑らかさ・最終的な見た目の品質は、
GPU が有効な実機で確認してください。**

## ファイル構成

```
index.html      キャンバス 1 枚だけ
styles.css      全画面固定・タッチ操作の抑止・セーフエリアの取得
src/main.js     ループ / 工程の遷移 / 誘導 / 完成画面の UI
src/stages.js   12 工程の定義と、工程ごとの小物（コンロ・レバー・蓋・冷蔵扉…）
src/art.js      描画層（型・皿・鍋・ボウル・注ぐ流れ・プリン本体）
src/view.js     枠から倍率を決める自動カメラ
src/input.js    寛容なジェスチャ認識（円 / 一方向 / 弧 / 長押し）
src/audio.js    WebAudio による効果音（外部アセットなし）
tests/smoke.mjs 1 周プレイして各工程のスクリーンショットを撮る
tests/moment.mjs 「型を抜く 3 秒」だけをコマ撮りする
```

デバッグ用に `window.__game` を公開しています
（`__game.jump('demold')` で任意の工程へ飛べます）。
