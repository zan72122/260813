# ジッパーハウス

**チャックをあけて、ものを下に落とす。**

4歳児向けの iPhone / iPad モバイルWebゲームです。
部屋を貫く長い床ジッパーのスライダーを一本指で引くと、ジジジジ…と歯が
左右へ分かれて床が開き、上の物がグラッ、グラグラ…と踏ん張ったあと、
ガタン！と床下のクッションへ落ちます。物理は常に上から下です。

## 遊びの分岐

ラウンドごとに部屋の仕掛けが変わり、「どこを・どの順で・どこまで開けるか」で
結果が分岐します。

1. **長い一本線** — v1の感触。奥ほど大きな物
2. **分岐路線** — Y字に分かれたジッパー。分岐点で指の向きに枝を選ぶ。
   選んだ枝の上の物だけが落ちる
3. **平行な2本線** — 物が2本の線をまたいで立つ。片線だけ開けると横に傾き、
   両方開けるとまっすぐ落ちる。ベンチは1本では落ちない
4. **天井の荷物ネット** — 頭上のネットのジッパーを開けた場所から、
   おもちゃが上から降ってくる。床のジッパーでさらに下へ
5. **2階建てタワー** — 各階の床に1本ずつ。上下の穴を揃えると
   ガタン！ガタン！と連鎖落下
6. 以降は要素を混ぜた無限リプレイ（配置・中身はシャッフル）

## カメラ

3/4俯瞰でスライダーに接写追従（ドラッグ中は固定して指と取っ手の対応を保証）。
物が落ち始めると穴と着地点が同時に入る画角へ寄り、着地を見届けて戻ります。
しばらく触らないと俯瞰へ戻り、すべての取っ手が見えます。多層ラウンドは
自動的に高め・引きの構図になります。

## 実行

ビルド不要の静的サイトです（three.js は `vendor/` に同梱）。

```sh
python3 -m http.server 4173
# → http://localhost:4173 を iPhone / iPad の Safari で開く
```

## 実装メモ

- ジッパーは「線分の木」への一般化（`Track`）。開口はスライダーの後方に
  伸びるレンズ形で、長く開けるほど幅も広がる（大物ほど長く開ける必要）
- 布は1枚の変形メッシュ＋アルファマップの動的切り抜きで、開いた区間だけ
  本当に穴が抜けて床下が見える
- 物の支持判定は5×5サンプリング。任意方向への傾き→踏ん張り→転倒と、
  多層の面交差判定による連鎖落下・途中の階への着地に対応
- 文字・点数・制限時間なし。逆方向に引いても壊れない。効果音は全てWebAudio合成

## テスト

```sh
npm install
CHROMIUM_PATH=/path/to/chromium npx playwright test  # スモークE2E（Chromium）
```

`?e2e=1` で乱数シード固定・影オフになり、`window.__game` に検証用フック
（トラック形状・開口長・物の状態・ラウンドジャンプ）が公開されます。
