# かまくらつくろう ⛄

雪国を知らない4歳児向けの「かまくら作り」体験ゲーム（iPhone/iPad モバイルWeb）。

「大きな雪山を作って、その中を掘るとお部屋になる」という空間の驚きを、
一指だけの操作（押す・ペタペタ・掘る・なぞる・置く）で体験します。

## あそびかた

1. 雪を左右から中央へスワイプして集める
2. 雪山をタップしてペタペタ固める
3. 大きなスコップで入口を掘る
4. 穴をタップして中へスルッと入る
5. 青白い雪壁を指でなぞって部屋を広げる
6. 暖色LEDランタンを置くと、部屋がやわらかい橙色に
7. 外から完成したかまくらを眺めて、もう一回！

文字説明・点数・失敗・制限時間はありません。実際の火は使わず、
電池式LEDランタンと見守りの大人キャラクターで安全に配慮しています。

## 実行

静的ファイルのみ。ローカル確認:

```
python3 -m http.server 8347
# → http://localhost:8347/index.html
```

## テスト（Chromium スモーク）

```
npm install
npm test
```

`?fast=1` クエリで演出短縮・決定的シードのE2Eモードになります。

## 技術メモ

- Canvas 2D のみ（WebGL不使用、SwiftShader環境でも安定）
- 絵画調レンダリング：昼→夕→ランタン橙を1本のパレット補間で統一ライティング
- ベイク済みテクスチャ（雪の粒ノイズ・層雲）＋ワールド永続地面レイヤー
  （足あと・雪玉の圧雪跡・落雪の小山がプレイの痕跡として残り続ける）
- 雪の質感：風紋・ダイヤモンドダスト・3層パララックス降雪・地吹雪・
  木からの落雪・入口断面の雪層・内部の工具痕と削りカス堆積
- 人物はセミリアル頭身の関節アニメーション（歩行・押し・かがみ・拍手・白い息）
- 効果音はすべてWebAudio合成：風の環境音ループ、雪踏みのギュッ、掘削、
  かまくら内部はローパス＋生成リバーブでこもった静けさ、完成時はオルゴール
- devicePixelRatio 上限2（E2Eモードは1）、縦横両対応（縦持ち専用カメラ構図あり）
- カメラはゲーム側が誘導（自由操作なし）: 雪原全景 → 雪山 → 入口接写 → 内部 → 外観リビール
