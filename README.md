# 色を吸うスポンジ（いろすいスポンジ）

4歳向けの iPhone / iPad モバイル Web ゲーム。
「色を吸って、混ぜて、ギューッと出す」だけの、文字のないカラフルなおもちゃです。

## あそびかた（一指操作のみ・文字なし）

1. スポンジをドラッグして色水（赤・青・黄）にひたす
   → 触れたところから色がスポンジにじわっと染み込む
2. べつの色水にもひたす
   → 二つの色がスポンジの中で出会い、境界がゆっくり混ざって新しい色になる
   （赤＋青→むらさき、黄＋青→みどり、赤＋黄→オレンジ）
3. 白い花・ゼリー・蝶・星の上まで運び、**指を止めたまま長押し**
   → スポンジがギューッと縮んで、色の滴がぽたぽた落ち、
   根元から先端へ色が広がる。つぼみなら開花、蝶なら飛び立つ
4. 透明な洗い場にひたすと色が少しずつ抜けて白にもどる
5. **いろのせいれい**：はじめて作った色を絞り出すと、その色の
   スライム妖精がその場で誕生！（全10種：赤・オレンジ・マンゴー・
   黄・きみどり・みどり・青・青むらさき・赤むらさき・ココア）
   妖精は庭に住みつき、ぴょんぴょん跳ねたり、スポンジを追いかけたり、
   お昼寝したりする。庭の隅の白いキノコの家は、妖精が生まれるたびに
   カサの水玉がその色に灯る＝文字のないコレクション図鑑。
   集めた妖精はブラウザに保存され、次に遊ぶときも庭にいる
6. **白い動物たち**：白いうさぎ・ことり・かえるも塗れる。色が
   足元から頭へ広がりきると命が宿り、うさぎは野原を跳ね回り、
   ことりは歌って空を一周し、かえるは大ジャンプする
7. **ガーデン成長**：塗った回数＋出会った妖精の数で庭そのものが育つ。
   レベル1で小さな蝶たちが住みつき、レベル2で丘に虹がかかり、
   レベル3で白い大木がぐんぐん生え、レベル4で大木が桜色に開花して
   花びらが庭中に舞う。成長も保存される
8. **濃淡（こさ）**：色水にさっと触れるとパステル、長くひたすと
   濃くて深い色。洗い場で軽くゆすぐと同じ色のまま淡くなる。
   1回の絞りは最初の濃さで塗り切るので、狙った濃さがそのまま出る。
   妖精も「色相10種×うすい・ふつう・こい」で最大30種類に
9. **小物いっぱい**：白いきのこ・石・フェンス・ベンチが庭中に
   散らばっていて全部塗れる。庭のすみずみまで自分の色にできる
10. **よる**：空の太陽をタップすると夜になる（月・星・ホタル）。
    夜だけ目を覚ます「月光の泉」にスポンジをひたすと光を吸い、
    その状態で絞った色は**闇の中でほんのり光る**。光る花、光る風車、
    光る妖精を作れる。月をタップすれば朝に戻る
11. **大物ランドマーク**：白い風車（塗ると羽根が回り出す）と
    白いコテージ（塗ると窓に暖かい灯りがともる。夜はもっときれい）
12. **色の小川**：庭の奥の白い泉に色を絞ると、色のかたまりが
    小川を流れくだり、途中の白い睡蓮をつぎつぎ染めて、
    最後に池ぜんぶがその色になる。ここに入れた色が向こうに届く
13. **おえかきボード**：手前の大きな白いシートの上で、色を含んだ
    スポンジを引きずるとお絵かきできる。長押しでまるいスタンプ。
    洗いたてのきれいなスポンジでこすると消える。夜は絵が光る

最初は光るリング（ハロー）が「赤い水 → 白い花」を誘導し、
次に二色混合へ、そのあとは自由モード。どの順番で何を混ぜても
きれいな色になる設計で、失敗・点数・制限時間はありません。

## 技術

- WebGL 3D（Three.js 同梱・ビルド不要の静的サイト）。透視投影・影・
  フォグによる空気遠近で、近景（草）・中景（プールと白い対象）・
  遠景（丘と雲）が分離した 3/4 俯瞰ビュー
- スポンジは頂点ごとに 3 原色の染料量を保持し、接触点から注入 →
  毛細管現象風の上方バイアス付き拡散で、染み込み・二色の遭遇・
  混色が連続的に見える
- 混色は減法混色（絵の具）ベース + 明度/彩度の再補正で、
  どんな組み合わせでも鮮やかな色に落ちる
- 吸収・混色・絞りの瞬間はカメラが自動で寄る
- 縦・横画面両対応（リサイズ / 回転で自動調整）

## 実行

```bash
npm install
npm start        # http://localhost:8137
```

iPhone / iPad の Safari で開けばそのまま遊べます（ビルド不要）。

## テスト

```bash
npm test         # Playwright Chromium スモーク E2E
```

`?e2e=1` を付けると描画ループが決定論モードになり、
`window.__game`（`press/move/release/step/state`）で
論理シミュレーション時間を直接進められます。
