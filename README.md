# 床ジッパー

**チャックをあけて、ものを下に落とす。**

4歳児向けの iPhone / iPad モバイルWebゲームです。
床に縫い付けられた巨大なジッパーのスライダーを一本指で引くと、
ジジジジ…と歯が左右へ分かれて床が開き、上に乗っている物が
グラッ、グラグラ…と踏ん張ったあと、ガタン！と床下のクッションへ落ちます。

## 遊び方

- 赤いリングの取っ手を指でつかみ、ジッパーに沿ってなぞる（多少ずれても自動補正）
- 開いた穴より大きい物は引っ掛かって落ちない → もっと長く開けると落ちる
- 全部落とすとジッパーが自動で閉じ、赤いストッパーが後ろへ下がって
  もっと長く開けられるようになり、より大きな物が登場する
- 文字・点数・制限時間・ゲームオーバーなし。間違った方向に引いても壊れません

## 実行

ビルド不要の静的サイトです（three.js は `vendor/` に同梱）。

```sh
python3 -m http.server 4173
# → http://localhost:4173 を iPhone / iPad の Safari で開く
```

## 実装メモ

- 床は左右2枚の変形パネル。開口幅に合わせて頂点をCPUで押し広げ、
  膨らみとめくれで「布が開く」を軽量に偽装（クロスシミュレーション不要）
- 開口はレンズ（目）形状：開けた長さが長いほど幅も広がるため、
  「大きい物ほど長く開ける」が数値表示なしで自然に伝わる
- ジッパーの歯は InstancedMesh、物体の傾き・踏ん張り・落下は
  条件を満たした瞬間だけ動く自前の軽量キネマティクス
- カメラは3/4俯瞰固定。ドラッグ中は完全固定（指と取っ手の対応を保証）、
  指を離すとスライダー位置へ滑らかに追従。落下時だけ少し床下を見せる
- 効果音はすべて WebAudio で合成（初回タッチで解禁）

## テスト

```sh
npm install
CHROMIUM_PATH=/path/to/chromium npx playwright test  # スモークE2E（Chromium）
```

`?e2e=1` を付けると乱数シード固定・影オフになり、`window.__game` に
検証用フック（開口長・物体状態・座標変換）が公開されます。
