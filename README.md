# びよーん！チーズのふくろ屋さん

4歳児向けのモバイルWebゲーム。白いチーズをお湯でやわらかくして、
びよーんと伸ばし、袋にして、トロトロを入れて、口をキュッと閉じる——
モッツァレラからブラータができるまでを、指ひとつで最初から最後まで作れます。

- 対応: iPhone / iPad の Safari(縦・横両対応)。PCブラウザでも動作
- 1プレイ: 約3〜5分
- 文字が読めなくても遊べる(絵・音・指ヒントで誘導)
- ゲームオーバー・採点・制限時間なし

## 起動方法

```bash
npm install
npm run dev        # 開発サーバ (http://localhost:5173, --host 付きでLAN公開)
```

iPhone/iPadで遊ぶには、同じWi-Fi内から `http://<PCのIP>:5173` を開きます。

## ビルド

```bash
npm run build      # 型検査 + 本番ビルド → dist/
npm run preview    # dist/ を配信して確認
npm run typecheck  # 型検査のみ
```

## テスト(スモーク)

```bash
npm run preview &
node scripts/smoke.mjs          # iPhone縦で全13モジュールを実プレイ+回転+リプレイ
node scripts/smoke.mjs --sizes  # iPhone/iPad×縦横のスクリーンショット確認
```

Chromium(SwiftShader)でポインタ操作を実際に行い、各工程の進行・
リプレイジャンプ・画面回転での状態保持・コンソールエラーを検証します。
スクリーンショットは `shots/`(または `SHOT_DIR`)に出力されます。

## 主要ファイル

| ファイル | 役割 |
|---|---|
| `src/main.ts` | 起動・結線 |
| `src/game.ts` | state machine、モジュール遷移、チェックポイント(途中再開) |
| `src/stage.ts` | 3Dセット(工房・職人ロボット・道具)、ライト、パーティクル |
| `src/cheese.ts` | チーズ変形: 延伸チューブ、パラメトリック袋メッシュ、リボン |
| `src/cameraRig.ts` | ショット指定型カメラ(自由カメラなし、縦画面自動補正) |
| `src/input.ts` | Pointer Events 一元管理(一次ポインタのみ、円運動検出) |
| `src/audio.ts` | WebAudioプロシージャル効果音 + 音声ガイド(差し替え可能) |
| `src/hint.ts` | 迷ったら出る指ヒント(なぞる軌跡を表示) |
| `src/ui.ts` | 導入の装飾選択・リプレイ選択・設定ボタン(DOM) |
| `src/modules/*.ts` | 各シーンモジュール(一場面一動詞) |

## ゲームループ(Module 0〜13)

0. 導入 — エプロン・ボウル・皿を選ぶ
1. 注ぐ — レバーを下げてお湯(職人が扱う)
2. 寄せる — カードを中央へ
3. **伸ばす — びよーん(看板体験)**: スワイプの長さ・速さが形に残る
4. 広げる — 放射スワイプで円盤に
5. へこませる/持ち上げる — 袋へ
6. 裂く/混ぜる — stracciatella作り
7. **入れる — トロッ**: 入れるほど同一画面で袋が膨らむ
8. 集める — 口に首を作る
9. **つまむ/ねじる — キュッ**
10. 沈める — 冷水でポチャン
11. すくう/置く — 皿へ
12. **開く — 中身がトロリ**: なぞる速さで流出が変わる
13. 再プレイ — 絵で選ぶ(2タップ以内で「びよーん」へ)

## 設計メモ

- 袋は soft-body ではなくパラメトリック面(深さ/縁/膨らみ/首/結び/開き)で安定変形
- 延伸は固定トポロジのチューブを毎フレーム更新(ばね追従+カテナリーたわみ)
- 音は全て WebAudio 合成。`AudioManager` のAPI名を保ったままサンプル音源へ差し替え可能
- 音声ガイドは speechSynthesis(ja-JP)があれば再生、なければ無音スキップ
- adaptive DPR(上限1.75)、影は1灯1024px、ポストプロセスなし
- 進行はメモリ内 state machine のため画面回転で失われない。装飾と設定は localStorage 保存
- 通信は一切なし(ログイン・広告・分析なし)

## 既知の制約

- 実機のGPU性能・音声(speechSynthesis の声質)は端末依存
- SwiftShader 上の自動テストでは FPS・見た目の最終品質は判定しない(実機確認を推奨)
