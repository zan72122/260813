# ぺちゃっ！ぎゅっ！ぺりっ！ のりこうじょう

4歳児向けのモバイルWebゲーム。iPhone / iPad の Safari で遊べます。
黒緑のどろどろを、混ぜて・流して・均して・押して・乾かして・ぺりっと剥がすと、
見慣れた四角い海苔になります。**画面に文字は一切出ません。**

## 遊び方（大人向けの説明）

| 工程 | 操作 | 起きること |
| --- | --- | --- |
| 1 まぜる | 桶の上を指でぐるぐる | どろどろが渦を巻く |
| 2 ながす | ひしゃくを枠の上へドラッグ | 黒緑の液が枠に落ちる |
| 3 ならす | 枠の上を左右にスワイプ | 面が四角く均一になり、水が下へ落ちる |
| 4 みずをぬく | スポンジを押しあてる | 端から水がにじみ出て、面が締まる |
| 5 かわかす | レバーを下へ引く | 送風機が回り、色が濃く・艶が減る |
| 6 ぺりっ | 手前のふちをつまんで引く | 乾いた海苔が音を立てて剥がれる |
| 7 かざす | 一枚を窓あかりの中へ運ぶ | 薄いところが透けて、光の粒が浮かぶ |
| 8 できた | （自動） | 海苔が重なり、おにぎりに巻かれ、お弁当になる |

制限時間なし、ゲームオーバーなし、後退なし。数秒迷うと次に触る対象が揺れて光ります。
「かざす」だけは放っておくと海苔が自分から光へ寄っていくので、そこで止まることもありません。

## 起動

```bash
npm start          # http://localhost:5173/
```

依存パッケージなしで動きます（ビルド不要・アセットなし・すべて手続き生成）。
実機で試す場合は、同じ Wi-Fi 上で起動時に表示される LAN の URL を iPhone / iPad で開いてください。

## 自動試遊（検証）

Playwright（`playwright` パッケージ）が必要です。

```bash
npm start &                     # サーバを起動しておく
npm run playtest portrait       # 縦画面で一周プレイ + 各工程のスクショ
npm run playtest landscape      # 横画面で一周
npm run playtest ipad           # iPad 横で一周
npm run preview portrait        # 各工程の見た目だけ素早く確認
TIER=0 npm run playtest portrait  # WebGL を使わない代替経路で一周
```

URL パラメータで検証用の指定ができます。

| パラメータ | 意味 |
| --- | --- |
| `?tier=0\|1\|2` | 品質段階を固定する（自動切替を止める） |
| `?pdb=1` | WebGL の描画バッファを保持する（スクリーンショット検証用） |

`playtest` は実際のポインタイベントを流して最初から最後まで自走し、
途中で画面を回転させて状態が壊れないことを確認し、`shots/` に各工程の画像を保存します。
ページエラーがあれば異常終了します。

## 構成

```
index.html          3層のキャンバスと iOS 向けの設定
server.js           依存ゼロの静的サーバ
src/main.js         ループ、ポインタ入力、回転対応、テスト用フック
src/game.js         工程のステートマシン、カメラ、誘導、剥がしの幾何、3層の描画
src/sheet.js        海苔の状態モデル（量・濡れ・押し・乾燥リング）と 2D 代替描画
src/scene.js        工房・桶・抄き枠・道具・おにぎり・お弁当・接地影
src/layout.js       縦横それぞれの「再構図」とカメラ矩形
src/fx.js           水滴・しぶき・湯気・きらめき
src/audio.js        WebAudio による効果音の合成（音声ファイルなし）
src/quality.js      端末性能に応じた品質段階の判定と自動切替
src/gl/sheetGL.js   海苔と水の WebGL レイヤ（法線・鏡面・透過・水膜）
src/gl/fiber.js     繊維マットの高さ場 → 法線・厚み・ムラ（起動時に一度だけ焼く）
src/util.js         数学・ノイズ
```

### 描画は3層

| 層 | 中身 | 技術 |
| --- | --- | --- |
| 下 | 工房・桶・抄き枠と簾 | Canvas 2D |
| 中 | **海苔と、その上の水** | WebGL |
| 上 | 手前のレール・道具・水滴・誘導・HUD | Canvas 2D |

WebGL が使えない端末では中層を隠し、下層に 2D で海苔を描く代替経路に落ちます。

### 品質段階

実測FPSを見て、重い効果から段階的に落とします（一度落としたら上げません）。

| 段階 | 内容 |
| --- | --- |
| 2 | 繊維1024x768 / 透過 / 水の屈折と玉 / 背景ボケ |
| 1 | 繊維512x384 / 透過 / 屈折と玉なし |
| 0 | WebGL を使わず Canvas 2D 経路 |

### コマ送り（ストップモーション）

世界は **1/12 秒きざみ**でしか動きません。カメラ・粒子・演出・リビールの進行はすべて
コマ単位で、コマごとに 1px 弱のブレと数%の露出ゆらぎが乗ります。手作りの物を
コマ撮りしている見え方になります。

ただし **指が触れているものは毎フレーム追従します**（ひしゃく・スポンジ・レバー・
剥がし・かざし）。幼児の操作感を落とさないための例外です。
下層（工房・抄き枠）はコマが進んだときしか描き直さないので、描画量も減ります。

### 設計メモ

- **状態は正規化グリッド**（0..1 × 0..1）で保持しているので、画面を回しても製造中の海苔は壊れません。
- **縦横は単なる回転ではありません。** 縦は「桶が上・枠が下」、横は「桶が左・枠が右」と、
  ワールド配置そのものを組み替えています（`src/layout.js`）。
- **剥がし**は、ヒンジを原点・指の方向を真下とするローカル空間で円弧として解いています
  （材料長 L が弦 d に収まるときの曲率半径 R を二分法で求め、`y = R sin(弧長/R)`）。
  行を曲線に垂直に回さないので、幅の広いシートでも扇状に割れません。
- **背景はワールド空間に一度だけ焼いて**毎フレーム貼るだけにしています。
  ボケ版も同時に焼き、工程ごとの被写界深度として重ねます。
- **素材は光で作っています。** 全オブジェクトが単一のキーライトを参照し、
  海苔は繊維の高さ場から起こした法線で陰影を計算します。
  持ち上がった所だけ、厚みの薄い部分が透けて光ります（`exp` ではなく
  厚みのしきい値で抜くので、面全体が光らずレース状になります）。
- **剥がれた面の行は剥離線と平行に保ちます。** 幅方向まで回すと s=0 の行が
  剥離線からずれて裂け目ができます。倒すのは「垂れる向き」だけです。
- **光にかざすと、キーライトが裏へ回ります。** 表の拡散反射が沈み、厚みの薄い所だけが
  透過で抜けます。透過量は 3乗カーブで潰してあり、線形のままだと面全体が
  一様な緑になって「苔」に見えます。
