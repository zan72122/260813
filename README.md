# とろっ！カクカク！にじビスマス工房

4さい（女の子）が、iPhone / iPad の Web ブラウザで、ひとりで さいごまで あそべる
ビスマス結晶づくりゲームです。

銀色の金属を **とろっ** ととかして、たねを置き、ひやして、余分をながし、
**カクカク** の階段結晶をとりだして、ライトの下でまわすと **にじいろ** に光ります。

- 縦・横 どちらでも遊べます
- 操作は ぜんぶ 一本ゆび（タップ・長おし・こする・上にひっぱる）
- 文字はほぼなし（すすみ具合は上の丸、やることはゆびのアニメで伝えます）
- **しっぱいなし**。まよっていると ヒントが出て、それでも触らなければ ひとりでに進みます
- **毎回ちがう石ができます**。しかも「ぐうぜん」ではなく、遊びかたで決まります

## 中心にあるしくみ：操作が そのまま 結晶を決める

このゲームには乱数の「当たり外れ」がありません。
子どもがやったことが 5 つの数字になり、それが 1 つの結晶を作ります
（`recipe → CrystalSpec → geometry` の純関数）。
ぜんぶ 本物のビスマス結晶づくりで 実際に効く要素です。

| つまみ | 操作 | 結晶への効き方 |
|---|---|---|
| **りょう** | かけらを 1〜5 個 入れる | 融液の量＝石全体の大きさ |
| **たね** | 液面を 1〜5 か所 タップ | そこから結晶が生える。近いと融液を取り合い、とても近いと**双晶**になる |
| **はやさ** | あおいで冷やす速さ | 遅い→段が厚く粗い／速い→段が細かく、枠が細く、**空洞（ホッパー）が深い** |
| **ながし** | 傾けて流す量 | 液面線。**そこより上だけが空気に触れて虹色になり、下は銀のまま** |
| **おんど** | 引き上げる瞬間の温度 | 酸化膜の厚み＝**色**。あついうちなら みどり・あお、さめてからなら きん・ぎん |

### いちばんの見どころ：引き上げ待ちの「色えらび」

結晶が液から顔を出すと、まだ熱いあいだ **目の前で色が流れていきます**。

```
みどり → あお → むらさき → あか → きん → ぎん
```

好きな色になった瞬間に、上にひっぱって引き上げる。それがその石の色になります。
本物の酸化膜の物理そのままで、しかも4歳児が「いま！」と言える遊びになっています。

## ずかん（28マス）

- **6色 × 4かたち = 24マス**
  - 色：ぎん・きん・あか・むらさき・あお・みどり
  - かたち：つみき・ふたご・たくさん・とんがり
- **レア 4マス**。運ではなく、操作の組み合わせで出ます（＝親が教えられます）

| レア | 出しかた |
|---|---|
| おうかん | たねを 4〜5 個 **輪に**置いて、ゆっくり冷やす |
| にじのしん | 流す量を **半分くらい**で止めて、**熱いうち**に引き上げる |
| たまごいし | たね 1 個・**急いで**冷やす・かけら 4 個以上（深い空洞の中に小さな石が入る） |
| きょだいばしら | たね 1 個・**ゆっくり**冷やす・かけら 5 個 |

できた石は ★1〜3 で評価され、ずかんに自動で記録されます。
ずかんの石にさわると、もういちど ライトの下でまわせます。

大きさが分かるように、仕上げでは **いつも同じ大きさの台座**に載せて見せます。

## あそびのながれ（7ステップ）

| # | やること | 指の動き |
|---|---|---|
| 1 | 金属のかけらを入れる | タップ（入れた数が 大きさ） |
| 2 | とかす | 長おし |
| 3 | たねを置く | 液面をタップ（1〜5か所） |
| 4 | すこし冷やす | 横に こする（うちわ） |
| 5 | かたむけて余分を流す | 横に ひっぱる |
| 6 | 好きな色で引き上げる | 上に ひっぱる |
| 7 | ライトの下でまわす | 横に こする |

## 走らせる

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # dist/ に出力
npm run preview    # http://127.0.0.1:4173 でビルド結果を確認

npm run lint       # eslint
npm run test:unit  # レシピ→結晶 の純関数テスト（ブラウザ不要・1秒）
npm run test:e2e   # iPhone縦 / iPad横 の一周テスト
npm test           # 上の3つを順に
```

`dist/` は静的ファイルだけなので、そのまま静的ホスティングに置けます
（`vite.config.js` の `base: './'` により、サブディレクトリ配信でも動きます）。

### ビスマスらしさの出しかた

本物の結晶成長計算はしていません。かわりに、

- **形**: 四角い枠（4本の棒）を段々に積んだ *ホッパー結晶*。上へ行くほど小さくなり、
  中央がへこむ。たねの数だけ生え、近いものは重なって双晶に見えます。
- **育ち方**: 頂点属性 `aLayer` / `aCenter` を使い、頂点シェーダで
  「その段の中心から外へ ぽん と広がる」動きにしています。何個生えても
  ドローコールは1回です。
- **色**: 酸化被膜の厚みで色が決まる、という本物のしくみをそのまま採用。
  厚みは「引き上げ温度」が土台で、段の高さと面ごとのばらつきが乗ります。
  ずかんの色名と画面の色がずれないよう、6色を「帯」にして
  帯のまんなかではほぼ純色になるようにしてあります。
- **液面線**: 液に浸かっていた部分には膜がつかないので、銀のまま残ります。

### 自動カメラ

自由カメラはありません。ステージごとに「注視点・見せたい半径・角度」を決めておき、
指数ダンピングで滑らかにつなぎます。距離はアスペクト比から計算するので、
iPhone の縦長でも iPad の横長でも同じ大きさに収まります。
仕上げだけは、結晶の実寸から半径を決めるので、**大きい石は大きく見えます**。

## クラウド実行での注意（CLAUDE.md 準拠）

- E2E は Chromium のみ・`workers=1`・`video=off`。
- `?fast=1`（または `E2E_FAST`）で devicePixelRatio を 1 に固定し、
  ポリゴン数・粒子数・アンチエイリアスを落とします。
- `window.__BISMUTH__` からゲーム状態を読み出せ、`tick(ms)` で
  論理時間だけを進められます（実時間待ちなしの決定論テスト用）。
  `tick(ms, 33, false)` で描画をとばせます。
- レシピ→結晶は純関数なので、いちばん大事な「操作で結果が変わる」性質は
  ブラウザなしの `npm run test:unit` で押さえてあります。
- SwiftShader 上での FPS・見た目の最終品質は評価しません。
  それは GPU のある実機 / CI で確認してください。
