# にじいろ霧吹き

4歳児向けのモバイル Web ゲーム。
**指で霧を噴くと、その霧の中から虹が生まれて育っていく。**

虹は最初どこにも存在しない。プレイヤーが作る。

```
何もない明るい庭
  → 長押しで霧がシュワーッと広がる
  → 水滴がきらめく
  → 霧の中に淡い虹がにじむ
  → 同じところへ重ねると太く鮮やかになる
  → 左右にふって弧を育てる
  → 画面を大きく横切る虹が完成
  → ごほうびに、ごく淡い二重虹と虹の粒
```

## 遊びかた

| 操作 | すること |
| --- | --- |
| 長押し | 霧を噴く |
| ドラッグ | ノズルの向き |
| 左右スワイプ | 虹の位置をさがす／弧を育てる |
| 短いタップ | 少しだけ霧 |
| 右下のボタン | もういちど、霧から作りなおす |

説明は要らない。最初に出る手のアニメーションが長押しと左右のふりを見せる。

## 動かす

依存ライブラリなし、ビルド不要。静的に配信するだけ。

```sh
npx http-server -p 8123 -c-1 .
# http://localhost:8123/
```

URL パラメータ:

- `?debug=1` … fps・虹の育ち具合などを表示
- `?seed=123` … 庭と虹を固定（見た目の再現用）
- `?e2e=1` … 自動テスト用の軽量モード（dpr 1・粒を控えめに）

## しくみ

### 虹はどこに出るか

本物と同じで、**対日点（太陽の正反対の点）から 42°** の位置。
太陽はプレイヤーの背後・高度 14° に固定してあるので、対日点は
つねに正面の地平線の少し下にあり、虹は正面に大きく立ち上がる。

科学的な関係は保ったまま、**当たり判定だけを実際よりずっと広くしてある**
（主虹半径の ±26%。本物は ±1° 程度）。
さらに、噴霧の向きと勢いを「指のま上あたりの弧」へ 72% だけ寄せている。
4歳児は左右にふるだけでよく、角度合わせはゲームが引き受ける。

### 虹が育つしくみ

弧を角度で 192 個のビンに分け、そこへ届いた霧の量を貯める
（`src/rainbow.js`）。

- 貯まった量 = その角度の虹の**濃さ・太さ・彩度**
- 隣のビンへ少しずつにじむので、弧はつながって見える
- ゆっくり薄れる（半減 24秒ほど）ので、作った虹はしばらく残る

画面に色を出すのは「いま霧がある場所」だけ。霧の濃度は 1/4 解像度の
バッファに描いてから虹シェーダで参照する。だから
**噴いた量と虹の鮮やかさが連続的に対応する**。

横画面は弧が長く見えるので、完成度は「角度のうち何割」ではなく
**「画面の横幅をどれだけ横切ったか」**で測る。縦でも横でも
同じくらいの手間で巨大な弧になる。

### 描画

WebGL2 のみ。1フレームあたりのドローコールは 15 程度。

| パス | 解像度 | 中身 |
| --- | --- | --- |
| 背景 | 1/2 | 空・雲・草地（手続き的に1パス） |
| 庭の飾り | 1/1 | instancing 1ドロー（草・花・木・噴水・小石） |
| 霧の濃度 | 1/4 | 加算。虹の出る場所を決めるためだけ |
| 霧 | 1/1 | 遠景=大きくやわらかいスプライト／近景=小さく細かい粒 |
| 虹 | 1/1 | 全画面 arc シェーダ（主虹・副虹・アレキサンダーの暗帯） |
| 水滴・きらめき | 1/1 | 少数の hero particles |
| bloom | 1/4 | 明部抽出＋2パスぼかし |

粒の数は上限で必ず止まる（近景 460 / 遠景 190 / 水滴 56 / きらめき 130）。
描画バッファは 175万画素・dpr 2 を上限にして、半透明の塗り重ねが
重くならないようにしてある。フレーム時間が延びたら静かに解像度を落とす。

虹は霧の「上に足す」のではなく、霧を虹の色で**置きかえて**いる。
足し算にすると濃い霧の中で色が白飛びしてしまうため。

### 毎回ちがうもの

虹の位置（太陽の方位）・太さ・主役になる色、
庭の草花と木と噴水の配置、花の色みの組みあわせ、霧の流れる風向き。

## ファイル

```
index.html      画面と、絵だけの UI
styles.css      UI（おしえてくれる手／もういちど／おと）
src/main.js     全体の進行・入力から霧まで・描画の順番
src/config.js   調整値（虹の角度、霧の量、粒の上限）
src/camera.js   3つの決められた構図（wide / spray / reveal）
src/rainbow.js  弧の蓄積と虹シェーダ
src/particles.js 霧・水滴・きらめき
src/scene.js    庭と霧吹き
src/post.js     bloom と最終合成
src/input.js    指ひとつぶんの入力
src/audio.js    手続き的な音（噴霧のノイズとベル）
src/glutil.js   小さな WebGL2 ヘルパー
```
