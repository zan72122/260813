# ぺたっ！きらっ！ ひみつホログラムこうじょう

4さいの女の子むけ、iPhone / iPad 用のモバイル Web ゲームです。
カードに **おして、はって、かたむける** と、にじいろが うごいて かくれた えが でてきます。

セキュリティ・ホログラム（パスポートや ID カードに貼ってある、傾けると虹色が動く
あのシール）を、子どもが自分で作れる工場に見立てたゲームです。

## あそびかた

| | | |
|---|---|---|
| 1 | **カードを えらぶ** | ねこ / ほし / おはな の 3しゅるい |
| 2 | **きらきらを えらぶ** | きらきら / なみなみ / はーと の 3しゅるい |
| 3 | **ぺたっ！** | カードを 3かい タップして、こまかい もようを おしこむ |
| 4 | **ころころ〜** | ゆびで なぞって、ホイルを てんしゃする |
| 5 | **かたむけて みてね** | できたカードを ドラッグ／たんまつを かたむける と、にじが うごき、かくれた えが あらわれる |

- ゆび **1本** だけ。タップと ドラッグ しかありません。
- **もじは さいしょうげん**、ぜんぶ ひらがな＋絵文字。
- **しっぱいなし**。タイマーも てんすうも ありません。
- 「↺ もういちど」で すぐ さいプレイ。
- **たてよこ 両対応**（縦は上下、横は左右にUIが回り込みます）。

## 実装メモ

### ホログラムの見せかた

本物のホログラフィー計算はしていません。角度依存の見た目だけを作っています。

- **波長ごとのフリンジ** — R/G/B を 3つの波長に見立て、回折の次数を
  `vec3(1.0, 1.13, 1.28)` 倍でずらします。1本の明暗エンベロープに色を掛けるだけだと
  2色しか出ませんが、チャンネルごとにずらすと本物の分光のように虹が流れます。
- **視線ベクトル** — カード接空間での視線 `ev` が、虹・ハイライト・きらめき・
  かくれ絵のすべてを駆動します。カードは 3D で回るので、遠近によって
  カード面内でも `ev` が変化し、帯が自然に流れます。
- **かくれ絵** — 視差でわずかにずれ、傾ける向きで「明るく出る／暗く沈む」が
  反転します（本物のホログラムの切り替え効果）。
- **アンチエイリアス** — `fwidth` で溝が 1px より細かくなる領域を検出し、
  中性のシルバーへフェードします（分解できない回折格子は白色光を返す、で物理的にも正しい）。
- **フィルミックな圧縮** — 加算した輝きは 1.0 を軽く超えるので、
  `1 - exp(-x)` で丸めます。ハードクリップだと白い塊になります。

### 素材

画像ファイルはありません。カードの絵、ギヨシェ（偽造防止の彫刻模様）、
微細レリーフ、かくれ絵、音は、すべて実行時に Canvas 2D と WebAudio で生成します。

### 傾き入力

`TiltController` が 3つの入力を1つの値に混ぜます。

- **ドラッグ** — どの端末でも必ず動く基本操作。
- **端末の傾き** — `deviceorientation`。iOS は許可が要るので、
  「はじめる」ボタン（ユーザー操作）の中で要求します。断られても遊べます。
  画面の向きに合わせて軸を回転させるので、横持ちでも正しく傾きます。
- **アイドルの ゆらぎ** — 誰も触っていなくても、虹は止まりません。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック + 本番ビルド
npm run typecheck
npm run lint
npm test           # ユニットテスト (vitest)
npm run e2e        # Chromium スモーク E2E (playwright)
```

### 実機っぽい見た目を確認する

```bash
npm run preview
node scripts/playthrough.mjs shots iphone      # iphone | iphoneland | ipad | ipadland
```

一周プレイして各段階のスクリーンショットを `shots/` に保存し、
傾きに対する色の変化量をコンソールに出します。

### E2E について

`?fast=1` を付けると dpr 1、きらめきノイズと紙吹雪オフの軽量モードになります。
CI では WebGL が SwiftShader で動くため、**E2E は挙動だけを検証**します。
FPS・なめらかさ・最終的な見た目の品質は、GPU のある実機で確認してください。
