# ポケットいっぱいのおおきなバッグ

**チャックをあけると、なにかでてくる。**

4歳児向けの iPhone / iPad モバイルWebゲームです。
動物型リュック（クマ・カエル・ネコが交代）の表面にある、大小さまざまな
ジッパーポケットを一本指で開けて遊びます。

- 少し開けると、すきまから**目がのぞく**
- もっと開けると、中身が**ムギュムギュと詰まる**（開口が中身より小さいと出られない）
- じゅうぶん開けると**ポンッ！**と飛び出して床に転がる
- 大きなクマ人形は、大きなポケットを**ほぼ全開**にしないと出てこない
- 顔の**口（メインジッパー）**を開けると、床のおもちゃを吸い込んでパクパク食べる
- ぜんぶ食べたら、ごちそうさま→ぴょんぴょん退場→次の動物が新しい配置でやってくる

## 分岐する遊び

- どのポケットを・どの順で・どこまで開けるかは全部プレイヤーの選択
- ポケット配置は毎ラウンド手続き生成、中身も毎回シャッフル
- 中身は個性つき：ひよこは跳ねる、車は走る、ビー玉は5個散らばる、
  風船は浮かぶ（タップでパンッ）、ポーチはタップでさらに開く（マトリョーシカ）
- 開けたままの空きポケットは落ちてきた物を**パクッとキャッチ**して、また出せる
- 文字・点数・制限時間・ゲームオーバーなし。逆方向に引いても壊れません

## 実行

ビルド不要の静的サイトです（three.js は `vendor/` に同梱）。

```sh
python3 -m http.server 4173
# → http://localhost:4173 を iPhone / iPad の Safari で開く
```

## 実装メモ

- ポケットは共通の `Pocket` クラス：布パッチの頂点変形（レンズ形開口＋
  ふくらみ＋めくれ）、InstancedMesh の歯、ミニスライダーで構成
- 開口はレンズ形状で「長く開けるほど幅も広がる」。中身ごとの必要開口幅
  との比較だけで、のぞき／詰まり／飛び出しが決まる
- 飛び出した物は軽量2.5D物理（重力・床バウンド・山積みの押し合い・
  風船だけ浮力）。落下条件を満たした物だけが動く
- カメラは正面やや俯瞰で固定。縦横でバッグの体型が変わり（縦長⇔横長）、
  ポケットは向きに合わせて再配置される
- 効果音はすべて WebAudio 合成（ポケットの大きさでジジジの音程が変わる）

## テスト

```sh
npm install
CHROMIUM_PATH=/path/to/chromium npx playwright test  # スモークE2E（Chromium）
```

`?e2e=1` で乱数シード固定・影オフになり、`window.__game` に検証用フック
（ポケット状態・開口幅・座標変換・中身差し替え）が公開されます。
