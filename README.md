# じょせつしゃ ゴー！ ❄

雪国を知らない4歳児のための、ロータリ除雪車のモバイルWebゲームです。
文字の説明なしで、一度さわれば「雪を食べて、飛ばして、道を作る機械なんだ」と
わかることを目指しています。

## あそびかた (一本指だけ)

1. 画面にタッチすると除雪車が進み、前のオーガ(らせんの口)がグルグル回って雪壁を食べます
2. 食べた雪は吸い込まれて、上のシュートからドバーッと飛び出します
3. 指を左右に動かすと、雪の飛ぶ方向が変わります
4. 後ろをついてくるダンプトラックに雪を積んであげましょう (近くを狙えば自動で吸い付きます)
5. まっしろだった道に、濡れたアスファルトと黄色いセンターラインが現れます
6. 町の広場までつくと、子どもたちと雪だるまが迎えてくれます

制限時間・失敗・点数はありません。外した雪も路肩のかわいい雪山になるだけです。

## 起動方法

ビルド不要・依存なしの静的ページです。

```sh
# ローカルで
python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad/PC のブラウザで開く
```

`index.html` と `game.js` をそのまま GitHub Pages や任意の静的ホスティングに
置いても動きます。iPhone・iPad の縦横どちらにも対応しています。

## 演出とカメラ

カメラは自動です (自由カメラなし):

- タイトル: 雪に埋もれた町の全景
- プレイ中: 低い追従視点
- はじめての投雪・ダンプ満杯: 投雪の接写
- ゴール: 除雪後の道が一望できる引きの画

雪国の情景: 屋根雪とつらら、高い雪壁、赤白のスノーポール、雪に埋もれた
ガードレール、クローラの轍、濡れたアスファルト、青白い雪の影、弱い降雪、
家々の暖色の窓、煙突のけむり。

## 開発・テスト用 URL パラメータ

| パラメータ | 効果 |
|---|---|
| `?fast=1` | DPR=1・粒子削減・固定シード (E2E/低スペック用) |
| `?demo=1` | 自動プレイ入力 |
| `?t=秒` | 起動時に決定論的に指定秒まで進めてから描画 |
| `?aim=数値` | デモ中の投雪方向を固定 (-340〜250) |
| `?seed=数値` | ワールド生成の乱数シード |
| `?dbg=1` | `document.title` に内部状態を出力 |

`window.__game` から決定論的な状態 (mode / frontier / cleared / trucksFilled
など) と `step(sec)` を利用できます。スモークテストは `test/smoke.sh` を参照。
