# 水中砂城 (Underwater Sand Castle)

4歳児（特に女の子）向けの、iPhone / iPad で片手で遊べるモバイル Web ゲーム。

**「水の中なのに、砂を積んでお城を作る」**

不思議な色砂の入ったノズルを水中で押すと、砂はバラバラに散らずに
「ニュルッと出て・モコッとまとまり・積み上がり・その形のまま残る」。
指でなぞった軌跡がそのまま塔や壁になり、最後に城門の穴を小魚が通り抜ける。

- 開始から完成・再プレイまで一周で 3〜5 分
- 文字が読めなくても遊べる（操作は「押す・動かす・積む・つなぐ・開ける」だけ）
- 縦画面 / 横画面それぞれ専用のカメラフレーミング
- 音量・明るさ・動き（揺れ）の設定つき

## 遊びかた

| 操作 | 動き |
| --- | --- |
| 長押し | 押している間だけ砂が出る |
| 押したままドラッグ | 指の軌跡に沿って砂が積み上がる |
| 指を離す | すぐ止まる |
| 大きな砂容器をタップ | 色を変える |
| 吸引ノズル（自由モード）でなぞる | 一部を取り除く |

ピンチ・二本指・端末を傾ける操作・自由カメラ回転はいっさい不要。
奥行き（Z）はゲーム側が補助するため、指は画面上の 2 次元だけを動かせばよい。

## ゲームループ

1. **導入** — 水面の上で乾いた色砂がサラサラこぼれる → ノズルごと水中へ潜る（音がこもり、泡が上へ流れる）
2. **最初の吐出** — 海底の大きな円形ガイド。最初のひと押しだけは、大きくゆっくり「モコッ」と膨らむ
3. **塔** — 左右に 2 本。ノズルを上へ動かすと積み上がる
4. **壁** — 塔と塔をつなぐ。中央の城門は砂がよけて穴が残る
5. **城門のアーチ** — 穴の上に橋を架ける
6. **飾り** — ピンク・水色・真珠・虹の砂容器が増える
7. **完成** — 城門が灯り、小魚が近づき・止まり・穴を通り抜け・塔のまわりを回る。カメラが引いて城全体を見せる
8. **もう一回** — 同じお城 / 別のお城（3 種のプロポーション）/ 完全自由モード

作った軌跡は完成後もそのまま残る。既成の城モデルに差し替えることはしない。

## 技術メモ

- Vite + TypeScript + Three.js（WebGL2、追加ライブラリなし、アセットファイルなし）
- **砂**: 1 つの `InstancedMesh`。ドラッグ軌跡を一定間隔でサンプリングして丸い塊を並べ、
  隣接塊へ視覚的にスナップ（weld）する。膨らみ・でこぼこ・粒感・消失アニメは
  インスタンス属性（誕生時刻・成長時間・シード・きらめき）からシェーダーで計算するので、
  一度置いた塊に CPU は二度と触らない。空間ハッシュで近傍・支持面を検索する。
  上限に近づくと側面塊を省略し、サンプリング間隔を粗くして描画予算を守る。
- **支持**: 近くに塊がなければ下の面まで落ちる。近くにあればそのまま留まる。
  だから塔の上から塔の上へ「橋」を架けられる。
- **ガイド**: パス上に並べたゴースト球のチェックポイント。砂が届いた球から溶けて消えるので、
  ガイドがそのまま進捗表示になる。城門の空洞は snap で砂をよけて必ず残す。
- **水**: 軽量シェーダー（波打つ水面、手続き的コースティクス、光のシャフト、漂う微粒子）。
  屈折・体積散乱・流体計算は使わない。
- **音**: すべて Web Audio で合成（音声ファイル 0 バイト）。水面を境にローパスで音がこもる。
- **性能**: adaptive DPR、端末ティアによる品質切替、`visibilitychange` 対応、
  Pointer Events + `touch-action: none`、safe-area 対応。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック + 本番ビルド
npm run typecheck
```

### デバッグ用 URL パラメータ

| パラメータ | 意味 |
| --- | --- |
| `?stage=towerL` | 任意のステージから開始（`foundation` `towerL` `towerR` `wall` `arch` `decor` `finale` `free`） |
| `?stage=free&build=1` | 城を自動で組んだ状態で開始 |
| `?low=1` | 低スペック向け品質を強制 |

### 実機相当の自動プレイテスト

Chromium（Playwright）で実際に一周操作してスクリーンショットを撮る。

```bash
node tools/fullrun.mjs phone       # 縦画面で一周
node tools/fullrun.mjs phoneLand   # 横画面で一周
node tools/fullrun.mjs pad         # iPad 横で一周
node tools/robust.mjs              # 短押し / 長押し / 高速ドラッグ / 画面回転 / 復帰
node tools/stress.mjs              # セグメント上限
node tools/audio2.mjs              # 水上→水中の音のこもり具合を計測
```

出力は `playtest-shots/`。
ソフトウェアレンダラ（SwiftShader）で走るため、FPS と最終的な見た目の評価には使えない。
