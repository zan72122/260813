# チタンいろそだて — Titanium Anodizing Game

4歳向けのiPhone/iPad モバイルWebゲーム。銀色のチタンのチャーム（星・蝶・花）を
陽極酸化の槽に沈め、大きなレバーを押さえている間だけ表面の酸化皮膜が育ち、
金 → 紫 → 青 → 水色 → 緑 →（その先の二次色）へと連続的に色が変わります。
好きな色になった瞬間に指を離せば、そこで止まります。

塗装や色選びではなく、**銀色の金属そのものが処理で色を持つ**不思議さが主役です。
発色は three.js の MeshPhysicalMaterial 薄膜干渉（iridescence）による実際の
干渉計算で、完成後は暗い展示台で指で傾けると照明角度に応じて干渉色が揺らぎます。

## 遊び方（文字なし・一指操作・失敗なし）

1. トレイの銀色チャームをタップ → ホイストが吊り上げて槽へ沈める
2. 画面のどこでも押さえる → レバーが入り、泡が立ち、色が育つ。離すと止まる
3. 好きな色で ↑ ボタン → 引き上げ（滴が落ち、濡れた金属の艶）
4. 暗い展示台へ。ドラッグで傾けて干渉色の揺らぎを鑑賞
5. ↻ ボタンで次のチャームへ（完成品はコレクション棚に並ぶ）

## 実行

静的ファイルのみ。任意のHTTPサーバーで配信:

```bash
python3 -m http.server 8734
# → http://localhost:8734/ をiPhone/iPad(Safari)で開く
```

## 開発

```bash
npm install
npm run build   # src/ -> app.js (esbuild bundle)
npm test        # Playwright playtest: 縦・横・iPadで全フローを自動試遊
```

- `src/main.js` — 状態機械（選択→浸漬→通電→引き上げ→展示）、カメラ、入力
- `src/pieces.js` — チタンチャーム形状と薄膜干渉マテリアル（TiO2 IOR 2.35、
  膜厚105nmバイアス + 成長12nm/s で titanium anodizing の色順を再現）
- `src/environment.js` — 工房（ベンチ・槽・ホイスト・レバー操作台・技術者・展示台）
- `src/water.js` — 簡略液体（フレネル水面・電解泡・滴・煌めき）
- `src/audio.js` — 合成音（ハム・泡・水音・チャイム、アセット無し）

WebGL 3D（透視投影・遮蔽・実ジオメトリ・PBR metallic + iridescent + 影 + フォグ）。
近景=レバーと槽の縁 / 中景=槽とチャームと技術者 / 遠景=棚・窓・ドラム缶の工房。
