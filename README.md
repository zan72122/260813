# ぎゅっと！にじちからラボ

**とうめいなものを ぎゅっと おすと、にじが でる。**

iPhone / iPad のブラウザでそのまま遊べる、4歳（女の子）向けのモバイル Web ゲームです。
テーマは **光弾性（photoelasticity）による応力観察** ——
偏光板ではさんだ透明な模型に力をかけると、力の集まった場所に虹色の縞（フリンジ）が現れる、
あの理科室の実験そのものを、指1本のあそびにしました。

```
とうめい（まっ黒）  →  ゆびで ぎゅっ  →  にじが ブワッ
```

## あそびかた

| | |
|---|---|
| **そうさ** | 画面を指1本でさわる／おしつづける。2本目の指は無視されます |
| **もじ** | ひらがなだけ・ごく短く。ボタンはぜんぶ絵 |
| **しっぱい** | ありません。減点も、時間制限も、ゲームオーバーもなし |
| **むき** | たて・よこ 両対応（iPhone / iPad どちらでも） |

### タイトル

さわらなくても、模型が勝手に押されて虹が咲きます（自動デモ）。
**タイトル画面の模型は、そのまま指でさわれます** —— はじめての一回を待たせません。

### ラボ（じゆうにあそぶ）

3つの透明模型を切りかえて、好きなだけ押せます。

- **はし** — 橋げた。押した所から支え（橋脚）へ、力の流れが虹になって走ります。
  丸いつまみ（↔）を指でドラッグすると **支えの位置を動かせます**。支えを動かすと縞のかたちが変わります。
- **アーチ** — アーチ橋。てっぺんを押すと、力がアーチに沿って足もとへ流れていきます。
- **おはな** — 花びらを押すと、その花びらの付け根に虹がたまります。

道具ボタン：

- 🏋 **おもり** — 模型の上に重りを落とします（最大4つ）。指を離しても虹はのこります。
- ↺ **はじめから** — 重りを消して、支えの位置を戻します。

### チャレンジ（3つ）

| | もくひょう | やること |
|---|---|---|
| 🧸 **くまさん** | くまさんを橋のむこうへ | 指で橋をささえているあいだ、くまさんが渡ります |
| 🌈 **にじの あし** | 虹をアーチの足もとまで | アーチをぎゅーっと押して、両方の足もとの輪を光らせます |
| 🌸 **にじの おはな** | 虹の花を大きく咲かせる | 花をぎゅっと押すほど、花びらがひらいていきます |

どれもクリアすると ⭐⭐⭐ が出るだけ。失敗はありません。

## 見せかた（自動カメラ）

作業中に自由カメラは使いません。ゲームが決まった順でカメラを動かします。

```
実験台の全景  →（約1秒）→  模型の接写  →  クリア時は結果確認（すこし引く）
```

カメラは上下の HUD（ボタン）にかくれない範囲を計算して構図を決めるので、
たて画面でもよこ画面でも模型が見切れません。

## 仕組み（疑似応力場）

有限要素解析はしていません。光弾性写真の *見え方* を、次の4つを足すだけで作っています
（`src/sim/stress.ts`）。

1. **荷重点の集中応力** — 点荷重まわりの `1/r` 減衰（Flamant 解のかたち）。
   そのままだと模型全体が光ってしまうので、ゆるやかな包絡線をかけて指のまわりに集めています。
2. **支点の反力** — 荷重を支点までの距離の2乗に反比例して配分。近い支えほど多く受け持ちます。
3. **力の流れ** — 荷重点と支点をむすぶ帯（主応力線のかわり）。橋やアーチの縞はこれで出ます。
4. **はりの曲げ** — 橋げただけ、単純ばりの曲げモーメント `M(x)` から `σ ∝ M·y` を加算。
   中立軸（まん中）に黒い線がのこる、本物の橋の縞模様になります。

出したフリンジ次数 N を、実写の干渉色をなぞった **虹色 LUT**（`src/render/lut.ts`）で色にします。

- N = 0 → **まっ黒**（＝直交ニコルで力が0の透明体）
- N が増える → 青 → 緑 → 黄 → 赤 → 紫 …と虹が何周もし、高次ほど淡くなる

描画は「暗いガラスの下地 → 応力場を **加算合成** で重ねる → ふちの光」の順。
加算合成なので、力ゼロの場所は自動的に黒いまま（何も足されない）＝ *押した所だけ光る*。

応力場は画面より粗い格子（4 CSS px ごと）で計算し、模型の形でクリップして拡大描画しています。
1フレームのセル数には上限があり、低スペック端末でも 60fps を保てます。

## 動かす

```bash
npm install
npm run dev          # 開発サーバー（http://localhost:5173）
npm run build        # 型チェック + 本番ビルド（dist/）
npm run preview      # ビルド結果を配信（http://127.0.0.1:4173）
```

`dist/` は相対パス出力なので、静的ホスティングにそのまま置けます。

### URL パラメータ

| | |
|---|---|

## テスト

```bash
npm run test          # 型チェック → ユニット → E2E をこの順で
npm run test:unit     # 疑似応力場と虹色 LUT（ブラウザなし・12件）
npm run test:e2e      # Chromium で iPhone / iPad 相当の4サイズ × 11シナリオ
node scripts/shoot.mjs        # 各画面サイズの試遊スクショを test-results/visual へ
node scripts/playthrough.mjs  # 本物のポインタ操作で実時間の一周試遊（fps も出る）
```

ユニットテストは物理のつじつまを見ます —— 力ゼロならまっ黒、押した所が最大で離れるほど暗い、
まん中を押せば左右対称、近い支えほど反力を受け持つ、曲げモーメントは支点で0・荷重点で最大、
中立軸では曲げの寄与がぴったり0、次数が上がると虹が周回して淡くなる。

E2E は iPhone / iPad 相当の 4 サイズ（たて・よこ）で、実際に一周遊んで確かめます。

テストは `window.__lab`（決定論 API）を使って論理時間を直接すすめるので、実時間を待ちません。

```js
window.__lab.pressAt(x, y);   // 指を置く（world 座標）
window.__lab.step(1 / 60, 60); // 1秒ぶん進める
window.__lab.orderAt(x, y);   // その場所のフリンジ次数（＝虹が出ているか）
window.__lab.snapshot();      // モード・進捗・カメラなどの状態
```

確かめている内容：

- **はじめの30秒**（実時間）：2秒で自動デモが虹を出す／迷うボタンは2つだけ／
  はじめて指を置いて1.2秒ではっきり虹になる／離すと1秒でまた透明にもどる
- タイトルで、さわる前から「おすと虹が出る」が自動デモで見えている
- タイトルの模型も直接さわれる（はじめの一回を待たせない）
- 3模型すべてで、押す前は真っ黒 / 押すと虹（フリンジ次数 > 1）
- おもりを置くと指を離しても虹がのこる、支えをドラッグで動かせる
- チャレンジ3つがすべてクリアできる
- 自動カメラが 全景 → 接写 の順に動く（勝手に自由カメラにならない）
- どの画面サイズでもボタンが画面外にはみ出さず、40px 以上ある
- 2本目の指が無視される

## 構成

```
src/
  main.ts              起動
  engine/  camera.ts   自動カメラ（全景/接写/結果、HUD を避けた構図）
           input.ts    一本指だけのポインタ入力
           audio.ts    縞が1本増えるたびに鳴る音（失敗音はなし）
           util.ts     数学ヘルパー
  sim/     stress.ts   疑似応力場（集中応力・反力・力の流れ・曲げ）
           models.ts   透明模型3種（橋・アーチ・おはな）
  render/  lut.ts      光弾性の虹色テーブル
           photoelastic.ts  ガラス下地＋フリンジの加算合成
           scene.ts    実験台・くまさん・おもり・目標マーク
  game/    game.ts     モード遷移・チャレンジ・カメラ演出
           challenges.ts  チャレンジ定義
  ui/      hud.ts      DOM の大きなボタン
           icons.ts    インライン SVG アイコン（絵文字フォントに依存しない）
```
