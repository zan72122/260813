# かまくらつくろう ⛄

雪国を知らない4歳児向けの「かまくら作り」体験ゲーム（iPhone/iPad モバイルWeb）。

「大きな雪山を作って、その中を掘るとお部屋になる」という空間の驚きを、
一指だけの操作（押す・ペタペタ・掘る・なぞる・置く）で体験します。

## あそびかた

1. 雪を左右から中央へスワイプして集める
2. 雪山をタップしてペタペタ固める
3. 大きなスコップで入口を掘る
4. 穴をタップして中へスルッと入る
5. 青白い雪壁を指でなぞって部屋を広げる
6. 暖色LEDランタンを置くと、部屋がやわらかい橙色に
7. 外から完成したかまくらを眺めて、もう一回！

文字説明・点数・失敗・制限時間はありません。実際の火は使わず、
電池式LEDランタンと見守りの大人キャラクターで安全に配慮しています。

## 実行

静的ファイルのみ。ローカル確認:

```
python3 -m http.server 8347
# → http://localhost:8347/index.html
```

## テスト（Chromium スモーク）

```
npm install
npm test
```

`?fast=1` クエリで演出短縮・決定的シードのE2Eモードになります。

## 技術メモ

- Canvas 2D のみ（WebGL不使用、SwiftShader環境でも安定）
- devicePixelRatio 上限2（E2Eモードは1）
- 縦横両対応（カメラのcontainフィットで構図を維持）
- カメラはゲーム側が誘導（自由操作なし）: 雪原全景 → 雪山 → 入口接写 → 内部 → 外観リビール
- 効果音はWebAudio合成（初回タップで初期化、iOS対応）
