# みずのまち

机の上のミニチュア都市に雨をふらせて、**水のいきさきを変えてあそぶ**実験ゲーム。
4歳児（文字が読めない子）向け。iPhone / iPad の Safari を想定。

災害のこわさを見せるゲームではありません。おもちゃの街と水の実験です。

## あそびかた（文字はいっさい出ません）

```
かわいた街を見る（ゆびが ▶ を指さしている）
  → ▶ をおす        … 雨雲が来て、同じ雨がふる
  → 見る             … 一滴 → 細い流れ → 合流 → 水たまり → 越流
  → 水が地下へ入ると、ゲームが自分でとまる
  → ゆびが「詰まった排水口」を指さす
  → なにかひとつ変える  … 下の表の 4 つ
  → ↺ でリセット     … 街はかわいた最初の状態へ（変えた所はそのまま）
  → ▶ をおす        … まったく同じ雨。まえの水ぎわが点線で重なって見える
  → くらべる         … まえ / いま の 2 まいと、3 つのゲージ
```

「小さな 1 操作で、街中の水の行き先が変わった」と分かることが中心です。
同じ街を何度でも実験できます（ステージクリア型ではありません）。

### 4 つの介入

| 道具 | 何が起きるか | 地下 | こうえん |
|---|---|---|---|
| 詰まった排水口をそうじ | 葉っぱが飛び、渦を巻いて吸いこまれる | **0.00** | 無事 |
| 土のうを置く（3つまで） | 水が当たって左右へ分かれ、別の道路が濡れる | 0.47 | **水びたし** |
| 土のうで入口を 2 か所ふさぐ | ひろばに水が入らなくなる | **0.01** | **水びたし** |
| みぞをほる（スコップ） | なぞった線にそって、水が川へ流れていく | 0.26 | 無事 |
| 大きな排水口のふたを開ける | ひろばへ着く前に水を横取りする | 0.45 | 無事 |
| なにもしない | | 1.00 | 無事 |

**どの手にも裏がある**のが大事なところです。土のうで地下は守れますが、
行き場をなくした水は道路にあふれ、こうえんの前が水びたしになります。
組みあわせれば両方守れます（＝もう一回やってみる理由になる）。

### 立ち尽くさせないための仕掛け

* さわれる物は最初から光り、ゆびのしるしが「つぎにさわる所」を指す
* はじめの 1 回だけ、水が地下へ入った所でゲームが**自分でとまる**
* 道具はトレイのボタンから地図へ**そのままドラッグ**できる（タップして選んでもよい）
* 排水口のふたは**何度でも開け閉め**できる。土のう・みぞも、道具をもう一度おせば全部もどる
* 守るもの 3 つのバッジが街の上に浮かび、**雨の最中に**たまっていくのが見える

## 街のしくみ

* 道路は「かまぼこ型」＝まんなかが高い → 両側のみぞに細い流れができる
* 交差点はたいらで低い → 4 本の流れが合流する
* ひろばは街でいちばん低いおわん。入口は 2 か所だけ（＝土のうで止められる）
* 地下入口は、ひろばの中の穴。**まわりのふちを水面が越えたときだけ**入る
* 排水口が飲んだ水は地下管を通って川へ出る（断面カットで見せる）
* こうえんは道路より少しだけ高い。ふつうの雨では無事だが、
  土のうで道路の水がふくらむと、ふちを越えて入ってくる（＝裏目）
* ほったみぞは、西の川へ向かってかならず下る。
  そうしないと「ひろばから水を逃がす」というもっとも自然な思いつきが、
  街でいちばん低いひろばでは成立しない

### 雨の量の決め方

雨が強すぎると「何をしても水びたし」、弱すぎると「何もしなくても平気」になります。
**ひとつの良い手で守りきれる量**に合わせてあり、単体テストで固定しています。

### 水のあつかい

96×96 の height field 上で virtual pipe 法（Mei らの方式の簡略版）を解きます。
物理の正しさではなく、**4歳児に見える因果**をこわさないことを優先しています。

* 高い所から低い所へ / 壁に当たると回りこむ / 穴へ吸いこまれる / 流れ同士が合流する
* 水は 96×96 のビットマップ（3 倍解像度）に描いてから、アイソメへ 1 回で転送
* 浮遊物（葉・花びら・ボール）が流れの向きを見せる

### 「まったく同じ雨」

くらべる遊びなので、再現性は絶対条件です。

* 乱数は固定シードの xorshift のみ（`Math.random()` はゲーム中に一度も使いません）
* シミュレーションは 1/60 秒の固定ステップ。フレーム落ちしても結果は変わりません
* `resetWater()` は水だけを消し、介入（排水口の状態・壁）は残します

単体テストで「同じ条件 → 同じ数字」を、E2E で「1 回目と 2 回目がビットレベルで一致」を
それぞれ守っています。

## モバイルでの配慮

* 縦横どちらでも遊べる。たて長のときは見おろし角を急にして街を大きく見せる
* ボタンはすべて 44pt 以上、下段に固定（safe-area 対応）
* 実ピクセル数に上限を置き、フレームが重い端末では解像度を自動で少し下げる
* 音は最初のタップまで鳴らさない（iOS の制約）。ミュートボタンあり

> フレームレートと最終的な見た目は、GPU のある実機で確認してください。
> ヘッドレス（CPU ラスタライズ）の数字は目安になりません。
