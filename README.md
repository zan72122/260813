# くるくる！にじいろいしけんびきょう

4さいの女の子が、iPhone / iPad のブラウザで遊べる「偏光岩石薄片ごっこ」。

うすい石をけんびきょうで のぞくと、ふつうの光では じみな灰色。
でも **にじスイッチ**（偏光板）を入れると、とつぜん にじいろのモザイクになる。
そのまま ステージを **くるくる** まわすと、粒の色が つぎつぎ変わる。

4歳に伝えたいことは「**うすい石をのぞいて、まわすと色が変わる**」だけ。

## あそびかた

| | |
|---|---|
| ゆび1本 | ドラッグで ステージを回す / タップで 粒をさわる |
| もじ | ぜんぶ ひらがな。読めなくても 絵文字と色で分かる |
| 失敗 | なし。まちがえても 小さく光るだけで、へることは 何もない |

1. **じゆうに みる** … 目的なし。好きなだけ回して、きらきら光る粒をさわって集める
2. **さがしもの** … 「この いろ さがそう」の 色玉と同じ色に光る粒を 3つ見つけると ⭐⭐⭐

どちらのモードでも、こまっていると ヒントが 自動で出る（スイッチを指す → 回しかた →
最後は 目的の粒に 光るリング）。時間切れも 減点も ない。

## 薄片（プレパラート）

| | 名まえ | どんな石か（モデル） | 見どころ |
|---|---|---|---|
| ❄️ | こおりいし | 石英質の砂岩ふう。低いレターデーション | 白〜灰色ばかりの中に、ときどき色つきの粒 |
| 🌈 | にじいし | かんらん石玄武岩ふう。高いレターデーション | いちばんカラフル。回すと総とっかえ |
| ✨ | ほしぞらいし | 雲母片岩ふう。細長い粒がそろって並ぶ | すじの入った長い粒が きらり |
| 🥚 | たまごいし | ざくろ石の斑状変晶ふう | 丸い粒だけは 回しても暗いまま（等方体） |

## 色のしくみ（疑似表現）

本物の鉱物学計算はしていない。粒ごとに

- **向き** `theta0`（結晶の向き）
- **レターデーション** `nm`（干渉色を決める値）

を持たせて、

```
あかるさ = sin²( 2 × (theta0 + ステージ角) )     ← 回すと明暗する
いろ     = ミシェル・レビ色図ふうの nm → RGB 表   ← 粒ごとに固有
```

で見た目を作っている。4歳向けの調整として、

- 消光しても **まっ黒にはしない**（`EXTINCTION_FLOOR`）。いちばん暗いときも
  「その粒の色の暗いほう」なので、こわれたように見えない
- 干渉色は 彩度を上げて、くすんだ色をへらす
- 等方体（たまご）だけは 例外的に 暗いまま。「回っても変わらない粒もある」の発見になる

粒のかたちは ボロノイ分割 + ロイド緩和。片理のある石は、つぶした空間で
ボロノイを取ってから戻すことで 細長い粒にしている。

## 画面のながれ

```
タイトル → いしをえらぶ → 顕微鏡の外観（プレパラートが落ちてくる）
        →（自動カメラで接眼レンズへ寄る）→ 接眼レンズの中を全画面で観察
```

外観から視野までは 1つの canvas で連続的につないでいる。カメラは
接眼レンズのレンズ円を画面の視野円にぴったり重ねる位置まで寄るので、
切りかわりの継ぎ目がない。長く感じたら 画面のどこかを さわると とばせる。

## 縦横両対応

`layout.ts` が 実寸を測って、視野の中心・半径と 操作パネルの帯を計算し、
CSS 変数に書き出す。canvas と DOM の UI が 同じ数字を見るので ずれない。

- たて … 操作パネルは 下
- よこ … 操作パネルは 右

遊んでいる とちゅうで 画面を回しても、そのまま つづけられる（E2E で確認ずみ）。
セーフエリア（ノッチ・ホームバー）も `env(safe-area-inset-*)` で よけている。

## 動かす

```bash
npm install
npm run dev        # 開発サーバ
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルドしたものを配信
```

### テスト

```bash
npm run test:e2e   # Playwright（毎回ビルドしてから配信して実行）
```

iPhone 相当（390×844）と iPad 横（1024×768）で、

- タイトル → 観察 → にじスイッチ → 回転 → 粒をタッチ の一周
- さがしもの 3つ達成 → クリア → ⭐が カードにつく
- 遊んでいる途中の 画面回転
- 4種類すべてで「回すと ピクセルが実際に変わる」こと

を確認する。

### 試遊スクリプト

```bash
npm run preview &
node scripts/naive-play.mjs   # 「はじめて さわる子」のシミュレーション
node scripts/shots.mjs        # 実機サイズのスクリーンショット一式
```

`naive-play.mjs` は デバッグ用の近道をつかわず、**画面のピクセルを見て
お題の色をさがし、その場所を ゆびでさわる** だけで最後まで行けるかを確かめる。
「見て → まわして → さわる」で成立しているかの 確認になる。

## 実装メモ

- 依存は Vite / TypeScript / Playwright だけ。画像・音声ファイルは 0 個
  （顕微鏡も 干渉色も 効果音も コードで生成）。本番 JS は gzip 13KB 程度
- 音は WebAudio でその場で合成。iOS のために 最初のタッチで `resume()` する
- `?fast=1` で軽量モード（DPR 1・演出減・無音・ループアニメ停止）。E2E はこれを使う
- `window.__game` に 状態と操作の窓口を出している（テスト・動作確認用）
- 音の入切は タイトル画面の右上 🔊
