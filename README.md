# ロボットそうこ 🤖📦

4歳児向けの iPhone/iPad ブラウザゲーム。
物流倉庫の AGV(無人搬送ロボット)群制御シミュレーションを、
「渋滞をつくって、床に矢印を1本描いて、もう一度動かすと、みんなスイスイ」
という遊びに翻訳したものです。

## 遊びかた (文字なしで遊べます)

1. ▶ を押す — 48台のロボットが一斉に棚へ荷物を取りに行きます
2. 真ん中の細い通路は両方向通行(=設計ミス)。向かい合ったロボットが
   「お先にどうぞ」で止まり、後ろへ列が伸びて大渋滞になります
3. ■ で止めて、床を指でスワイプ — 大きな緑の矢印(一方通行)が通路全体に現れます
   - 棚の上をスワイプすると棚が消えて新しい通路(バイパス)が開きます
   - 矢印をタップすると消せます
4. ↺ でリセット — ロボット・荷物・注文は毎回まったく同じ
5. もう一度 ▶ — 矢印に従ってロボットの川がスイスイ流れ、
   赤い荷物は赤い口へ、青は青へ、黄は黄へ次々届きます
6. 全部届くと 🎉。仕事を終えたロボットは棚の下に潜って眠ります 💤

## 実行

ビルド不要・依存なし。`index.html` をブラウザで開くだけです。

```sh
npx serve .        # または python3 -m http.server
```

iPhone / iPad の Safari では横画面・縦画面どちらでも遊べます。

## 技術メモ

- 単一HTML、Canvas 2D(擬似3/4ビュー)、Web Audio、依存ライブラリなし
- グリッド経路network + A*(edge cost / 一方通行制約)
- セル占有reservation。正面衝突(2台)はあえて解消せず渋滞の種にする
- 3台以上の循環待ちはラウンドアバウト式に同時回転で解消
- 停滞時のlocal reroute(止まっているAGVのセルのみ回避、迂回コスト上限つき)
- 中央通路だけが双方向 + 低コスト(つるつるの床)= baseline渋滞の設計ミス
- 手すきのAGVはKiva式に棚下へ駐機して通路を塞がない
- シード固定の決定論シミュレーション(RESETで同一注文を再現)
- テスト用API `window.game`(`step/swipe/reset/metrics` など)
