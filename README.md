# とろっ！カクカク！にじビスマス工房

4さい（女の子）が、iPhone / iPad の Web ブラウザで、ひとりで さいごまで あそべる
ビスマス結晶づくりゲームです。

銀色の金属を **とろっ** ととかして、ひやして、余分をながして、
**カクカク** の階段結晶をとりだし、ライトの下でまわすと **にじいろ** に光ります。

- 縦・横 どちらでも遊べます
- 操作は ぜんぶ 一本ゆび（タップ・長押し・こする・上にひっぱる）
- 文字はほぼなし（すすみ具合は上の丸、やることはゆびのアニメで伝えます）
- **しっぱいなし**。まよっていると ヒントが出て、それでも触らなければ ひとりでに進みます

## あそびかた（6つのステップ）

| # | やること | 指の動き | 画面 |
|---|---|---|---|
| 1 | 金属のかけらを入れる | 画面をタップ | るつぼ寄り |
| 2 | 加熱する | 長おし | 炎がふくらむ |
| 3 | すこし冷やす | 横に こする（うちわ） | 段がひとつずつ ぽん と育つ |
| 4 | かたむけて余分を流す | 横に ひっぱる | しずくが受け皿へ |
| 5 | トングで持ちあげる | 上に ひっぱる | 結晶がせり上がる |
| 6 | ライトの下でまわす | 横に こする | にじいろに光って完成 |

できた結晶は **かざりだな**（左下のボタン）に自動でならびます。
たなの結晶をさわると、もういちど ライトの下でまわせます。

## 走らせる

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # dist/ に出力
npm run preview    # http://127.0.0.1:4173 でビルド結果を確認
npm run test:e2e   # iPhone 縦 / iPad 横 の一周テスト
```

`dist/` は静的ファイルだけなので、そのまま静的ホスティングに置けます
(`vite.config.js` の `base: './'` により、サブディレクトリ配信でも動きます)。

## つくり

```
index.html          画面の骨組み（キャンバス＋最小限のDOM UI）
src/main.js         起動・リサイズ・描画ループ・テスト用フック
src/game.js         ステージ進行・自動カメラ・入力の解釈
src/world.js        3Dシーン（るつぼ・炎・液体・トング・受け皿・ライト）
src/crystal.js      ホッパー結晶のジオメトリ生成（毎回すこし変わる）
src/shaders.js      ビスマスの虹色・とけた金属・炎などの GLSL
src/ui.js           DOM（ヒント・ことば・かざりだな・保存）
src/style.css       レイアウト（縦横対応・セーフエリア対応）
src/audio.js        WebAudio だけで作る効果音（音源ファイルなし）
src/rng.js          シード付き乱数（テストで形を固定できる）
```

### ビスマスらしさの出しかた

本物の結晶成長計算はしていません。かわりに、

- **形**: 四角い枠（4本の棒）を段々に積んだ *ホッパー結晶*。上へ行くほど小さくなり、
  中央がへこむ。段数・大きさ・ねじれ・双子結晶の有無はシードで変わります。
- **育ち方**: 頂点属性 `aLayer` / `aCenter` を使い、頂点シェーダで
  「その段の中心から外へ ぽん と広がる」動きにしています（ドローコールは1回）。
- **虹色**: 酸化被膜の薄膜干渉を `cos` パレットで近似。膜の厚みを
  「段の高さ＋面ごとのばらつき」で変え、見る角度（フレネル・屈折角）で
  色が回るようにしています。**まわすほど色が動く** のがこのゲームの山場です。

### 自動カメラ

自由カメラはありません。ステージごとに「注視点・寄り具合・角度」を決めておき、
指数ダンピングで滑らかにつなぎます。寄り具合は **見せたい大きさ（半径）** で
指定し、画面のアスペクト比から距離を計算するので、
iPhone の縦長でも iPad の横長でも同じ大きさに収まります。
縦向きでは画角を広げ、注視点を少し下げて、主役が下のボタンと重ならないようにしています。

## クラウド実行での注意（CLAUDE.md 準拠）

- E2E は Chromium のみ・`workers=1`・`video=off`。
- `?fast=1`（または `E2E_FAST`）で devicePixelRatio を 1 に固定し、
  ポリゴン数・粒子数・アンチエイリアスを落とします。
- `window.__BISMUTH__` からゲーム状態を読み出せ、`tick(ms)` で
  論理時間だけを進められます（実時間待ちなしの決定論テスト用）。
- SwiftShader 上での FPS・見た目の最終品質は評価しません。
  それは GPU のある実機 / CI で確認してください。
