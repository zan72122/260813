# サッ！ジュワ！パカッ！ティラミス

4歳児向けのティラミス制作ゲーム（iPhone / iPad、モバイルSafari、縦横対応）。

文字が読めなくても、指一本のタップ・スワイプ・ドラッグ・長押しだけで、
「浸す → 並べる → 覆う → 均す → 二段目 → 粉を降らせる → 冷やす → 切る → 断面が現れる」
という材質変化の一連を最初から最後まで体験できます。1周 2〜4分。

## 遊びの流れ（本編フルチェーン）

1. **コーヒーへ浸す** — サヴォイアルディを下へスワイプ。浸した時間で色・しなり・滴の量が変わる（失敗なし）
2. **並べる** — 真上視点で透明容器へドラッグ。近づくと磁石吸着で「ことん」
3. **クリームを絞る** — 長押ししながらなぞると、指の少し上からクリームが出て凹凸を覆う（ハイトマップ）
4. **ヘラで均す** — スワイプした場所が平らになる。数回で必ずきれいになる
5. **二段目** — 同じ操作をテンポ速めで繰り返し。容器側面から層が増えるのが見える
6. **ココア** — 篩を左右に振る／タップ。落下粒子は一時パーティクル、着地後は表面テクスチャへ統合
7. **冷却** — 冷蔵庫へスワイプ。時計絵文字の時間圧縮演出。冷却後は揺れが収まる
8. **切断** — 側面接写でナイフを下へなぞると切れ目が進む（事前分割メッシュで軽量に偽装）
9. **断面Reveal** — ケーキサーバーで一切れを持ち上げると、白と茶色の層が現れる（最終報酬）
10. **再プレイ** — 絵だけの選択肢（もう一度 / 違う容器 / 最初へ）。2タップ以内で再開

- 制限時間・ゲームオーバー・点数なし。3〜5秒迷うと手のアニメーションでヒント
- 効果音はWebAudioで生成（サッ！ジュワー ことん むにゅー すーっ さらさら スパッ！パカッ！）
- カメラは工程ごとに自動移動（自由カメラなし）
- 進行設定（容器の色など）は localStorage に保存

## 開発

```sh
npm install
npm run dev        # 開発サーバ
npm run typecheck  # 型検査
npm run build      # dist/ へビルド
npm run test:smoke # ビルド後、ヘッドレスChromiumで4つのviewport（390x844 / 844x390 / 820x1180 / 1180x820）を一周自動プレイ
```

`?fast=1` を付けると演出が高速化され、DPR=1・影なしの軽量モードになります（E2E用）。

## 技術構成

- TypeScript + Vite + Three.js（WebGL2相当で成立、外部通信・SDKなし）
- 入力は Pointer Events の単一ポインタのみ。スクロール・ピンチ・長押しメニューは抑止
- コーヒー浸透：ノイズ駆動のシェーダパラメータ（`onBeforeCompile`）
- クリーム：Canvasハイトマップ → displacement/bump/alpha
- ココア：使い捨てパーティクル + 表面Canvasテクスチャ
- 切断・断面：事前分割メッシュ + 縞シェーダ + マスク（ランタイムCSGなし）
- ゲーム進行：async/await によるフェーズ・ステートマシン（`src/game.ts`）
- E2Eフック：`window.__tiramisu.phase() / step() / gesture()` — ゲーム自身のヒント座標をそのまま自動入力に使う
