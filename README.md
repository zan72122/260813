# 結晶の中の虹の目

4歳児向けのモバイル Web ゲーム。

透明な結晶を台に置き、大きな偏光リングを回し、石そのものを回すと、
中に淡い色が生まれ、やがてカメラが結晶の内側へ入り、
黒い十字と虹色の同心円でできた巨大な「目」が画面いっぱいに開きます。

WebGL2 のみ。ビルド不要、依存ライブラリなし。

## 遊びかた

```
npm start          # http://localhost:8123/ を開く
```

指一本だけで遊びます。文字の説明はありません。

| 段階 | 操作 | 起きること |
| --- | --- | --- |
| ① 置く | どこかを1回さわる | 結晶が光学台へ降りてくる |
| ② 偏光リング | 画面を**ぐるぐる**なぞる | リングが回り、結晶の中に淡い色が生まれる |
| ③ 結晶を回す | **左右**にスワイプ | 模様が動く。近づくとカメラが寄っていく |
| ④ 中へ入る | （自動） | 結晶の表面を通り抜け、画面全体が干渉模様の世界になる |
| ⑤ 目を開く | **左右**＝回転／**上下**＝傾き | 目が中央に来ると、まぶたが開いていく |
| ⑥ 完成 | （自動） | 虹の輪が画面の外まで広がり、ゆっくり落ち着く |
| ⑦ もういちど | ボタンを押す | 別の模様を持つ新しい結晶になる |

その時さわる対象はいつも一つだけです。
迷っても進めるように、模様が中央に近いほど自動でそっと引き寄せられ、
時間がかかるほどその力が強くなるので、行き止まりにはなりません。

## 画面の作り

```
index.html          画面と非言語ヒント（SVG）
styles.css          ヒント・進み具合・もういちどボタン
src/main.js         起動とメインループ（テスト用の窓口 window.__game も）
src/game.js         段階の進行・カメラ・入力
src/renderer.js     描画の段取り（背景→台→結晶→全画面→ブルーム→合成）
src/shaders.js      GLSL。干渉像の計算はここに一本化してある
src/crystalDef.js   結晶ごとの個性（色・輪の数・十字の太さ・中心のかたち…）
src/mesh.js         結晶／偏光リング／台座のジオメトリ
src/glutil.js       WebGL2 の薄いラッパ
src/mat.js          行列とイージング
src/audio.js        やさしい音（WebAudio、素材ファイルなし）
src/hud.js          ヒント表示の出し入れ
```

### 模様のしくみ

干渉像は **視線の向きを光軸座標系へ移した2次元座標** だけから作っています。

```
視線ベクトル → 光軸座標系 → 面内成分 p → 干渉像
```

- 位相差は半径の 1.3 乗。高次では頭打ちにして、細かすぎる縞を出さない
- 黒い十字は消光位 `sin²(2(θ−偏光角))`
- 細い干渉色は波長ごとに周期をずらした余弦
- 太く柔らかな色領域は、位相差のゆっくりした周期に主役色を割り当てたもの
- 中心は位相差ゼロなので自然に暗くなり、そのすぐ外に明るい輪ができる

結晶を覗く描画と全画面の描画が**まったく同じ式**を使うので、
カメラが結晶の中へ入っていくあいだ、模様がつながったまま拡大します。

主役色はピンク／シアン／紫／金／エメラルド。
全部を同じ明るさにはせず、暗い領域を残して虹を際立たせています。

### 性能

- WebGL2 前提、後処理はブルームのみ（1/4 解像度で2パス）
- 描画は解像度スケール付きのオフスクリーンへ。60fps を割ると自動で下げます
- devicePixelRatio は 2 まで。高精細な端末では最初から 0.8 倍で描き始めます
- 高速点滅はありません。すべての変化は 0.5 秒以上かけて動きます

## テスト

実際のポインタ操作だけで最後まで進めるかを、縦画面と横画面で確かめます。

```
npm test
```

Playwright が必要です。ブラウザの場所を指定する場合は `CHROME_PATH` を使ってください。

```
CHROME_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome npm test
```

`window.__game` にテスト用の入口があります（`advance` で論理時間を直接進める、
`aim` で角度を指定する、`setMagnet` で補助を切る、など）。
