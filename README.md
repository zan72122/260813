# ぺたっ！きらっ！ ひみつホログラムこうじょう

4さいの女の子むけ、iPhone / iPad 用のモバイル Web ゲームです。
カードに **おして、はって、かたむける** と、にじいろが うごいて かくれた えが でてきます。

セキュリティ・ホログラム（パスポートや ID カードに貼ってある、傾けると虹色が動く
あのシール）を、子どもが自分で作れる工場に見立てたゲームです。

**にじの ながれる むきは、ゆびで なぞった むき。**
だから 同じ組み合わせを選んでも、二度と同じカードにはなりません。

## 実装メモ

### 指でなぞった向きが、溝の向きになる

ホログラムの正体は微細な溝の集合です。このゲームでは、なぞった指の向きを
そのまま溝の向きとして記録します（`src/core/field.ts`）。

**溝の向きは「軸」であって「矢印」ではありません。** 右になぞっても左になぞっても
できる格子は同じです。そのため方向を素直にベクトルで保存すると、行ったり来たり
なぞった瞬間に平均がゼロに打ち消され、格子が消えてしまいます。
そこで **角度を2倍にした `(cos2θ, sin2θ)`** で保存します。θ と θ+180° が同じ値に
写るので、往復ストロークが正しく積み上がります。

この表現からは、**コヒーレンス**（溝の揃い具合）が長さとして無料で出てきます。

| なぞり方 | ベクトル長 | 見た目 |
|---|---|---|
| ていねいに一方向 | 1 に近い | くっきりした虹の帯が流れる |
| ぐるぐる・往復で交差 | 0 に近い | 銀色にきらめく乱反射 |

どちらもきれいなので失敗はありません。4歳は結果の違いを楽しみ、5〜6歳は
「ていねいに塗ると虹、めちゃくちゃに塗るとキラキラ」という理由に気づけます。

なぞる **速さ** は溝の細かさ（`PITCH_MIN`〜`PITCH_MAX`）になります。
ゆっくり＝細かい虹、はやく＝太い虹。

#### シェーダ側の注意点

軸から向きベクトルを復元すると **符号が任意** になります（`gdir` と `-gdir` は同じ軸）。
これは `order` を **偶関数（cos）にしか通さない**限り完全に打ち消されます。
`order` を奇関数に入れたり、位相オフセットを足したりすると、符号が反転する曲線に
沿って偽の継ぎ目が現れます。

同じ理由で、アンチエイリアスは `fwidth(order)` ではなく溝の細かさから見積もっています。
`fwidth` は反転曲線で無限大に跳ね、そこに銀色の線を描いてしまうためです。

### ホログラムの見せかた

本物のホログラフィー計算はしていません。角度依存の見た目だけを作っています。

- **波長ごとのフリンジ** — R/G/B を3つの波長に見立て、回折の次数を
  `vec3(1.0, 1.13, 1.28)` 倍でずらします。1本の明暗エンベロープに色を掛けるだけだと
  2色しか出ませんが、チャンネルごとにずらすと本物の分光のように虹が流れます。
- **キネグラム** — 隠し絵は4コマのアトラス。左右に傾けるとコマが進み、
  おほしさまが ウインクし、おさかなが およぎ、ハートが ドキドキします。
  上下に傾けると 明るく浮くか、暗く沈むかが 反転します（本物の切り替え効果）。
  隠し絵は **はんこを押した場所** に出ます。
- **ひみつライト（UV）** — 実在のセキュリティ要素。光るのは
  **自分が ころころした みち** そのものです。
- **フィルミックな圧縮** — 加算した輝きは 1.0 を軽く超えるので `1 - exp(-x)` で
  丸めます。ハードクリップだと白い塊になります。

### たな（保存）

画像ではなく **材料** を localStorage に保存します（`src/game/album.ts`）。
どのカード・どのはんこ・押した座標・なぞった軌跡（間引いた折れ線と速さ）だけ。
開くときに全ストロークを再生してカードを組み直すので、1枚あたり数KBで済み、
記録が完全であることも保証されます。

再生を完全一致させるため、**実際に描くのは記録された点だけ**です
（記録より細かく描くと、再生時に別のカードになってしまいます）。

### 傾き入力

`TiltController` が3つの入力を1つの値に混ぜます。

- **ドラッグ** — どの端末でも必ず動く基本操作。
- **端末の傾き** — `deviceorientation`。iOS は許可が要るので
  「はじめる」ボタン（ユーザー操作）の中で要求します。断られても遊べます。
  画面の向きに合わせて軸を回転させるので、横持ちでも正しく傾きます。
- **アイドルの ゆらぎ** — 誰も触っていなくても、虹は止まりません。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック + 本番ビルド
npm run typecheck
npm run lint
npm test           # ユニットテスト (vitest)
npm run e2e        # Chromium スモーク E2E (playwright)
```

### 実機っぽい見た目を確認する

```bash
npm run preview
node scripts/playthrough.mjs shots iphone      # iphone | iphoneland | ipad | ipadland
```

一周プレイして各段階のスクリーンショットを `shots/` に保存し、最後に
**「なぞる向きを変えると、どれだけカードが変わるか」** を数値で出します。

### E2E について

`?fast=1` を付けると dpr 1、きらめきノイズと紙吹雪オフの軽量モードになります。
CI では WebGL が SwiftShader で動くため、**E2E は挙動だけを検証**します。
FPS・なめらかさ・最終的な見た目の品質は、GPU のある実機で確認してください。

E2E には「同じカード・同じはんこでも、**なぞる向きが違えば別のカードになる**」
「**同じ軌跡なら完全に再現される**」の2本が入っています。前者がこのゲームの
おもしろさの核で、後者が たな の正しさの根拠です。
