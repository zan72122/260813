# ほんものイオン！100えんおかいもの

イオン具志川店（イオン琉球ネットスーパー）の**実在商品・実売価格150件**だけを使った、
4歳児向けの「金銭感覚」体験Webゲームです。

足し算ドリルではありません。
「10円・30円・50円・80円・100円で、本物のお店では何が買えるのか（そして、いかに買えないか）」を、
硬貨・カゴ・レジの体験を通して身体的に学びます。

> **本作はイオン株式会社・イオン琉球株式会社の公式アプリではありません。**
> 公開されている店頭価格を教材として利用した非公式の教育用ゲームです。

## あそびかた

ブラウザで `index.html` を開くだけです（ビルド不要・依存ゼロ・オフライン動作）。

```
# ローカルサーバー推奨（file:// 直開きでもフォールバックで動作します）
python3 -m http.server 8000
# → http://localhost:8000/
```

iPhone / iPad の縦・横画面両対応。タップとドラッグだけで遊べます。

### モード

| モード | 内容 |
|---|---|
| 🛒 おみせで おかいもの | 財布を選ぶ → 売場を見る → 買えるか調べる → カゴ → レジで硬貨を払う → 残った硬貨を見る |
| 📟 ピッ！スキャナー | 価格を隠した棚をスキャンして「いまのお金で買えるか」を調べる |
| ⚖️ 100えんライン | 「100円で買えそう / 100円より高そう」を予想してカードを振り分ける |
| 👛 どの おかね？ | その商品を買える一番小さい財布（10/30/50/80/100円）を探す |
| 📖 かかくずかん | 発見した実在商品を最小予算カテゴリ別にコレクション |

### 設計ルール

- **価格はDBの `game_price_yen` のみ**。丸め・値引き・架空商品・架空価格は一切なし
- 100円以下は実数表示、**101円以上は「100えんより たかい」**（子ども画面に101以上の数字を出さない）
- 硬貨は実在の 1・5・10・50・100円のみ（30円=10円×3、80円=50円+10円×3）
- 買えないことは失敗ではない（減点・赤×・制限時間なし）。買えない商品が棚の大半を占めるのは現実そのまま
- 発見済み商品・図鑑・音量設定は `localStorage` に保存（アカウント不要）

### 親モード

ホーム右下の 🔒 を**1.5秒長押し**すると、店舗名・データ取得日・JAN・税抜/税込価格・
検証レベル・出典URLの全件一覧と、セーブデータの初期化ができます。

## データ層

商品データはコードから分離されています。

- `data/products.json` … 唯一の価格ソース（イオン具志川店 2026-08-13 取得の実価格DB）
- `data/products.js` … `file://` 直開き用の自動生成フォールバック（JSONのコピー）

同じスキーマのJSONに置き換えるだけで、他店舗・別日・家庭のレシート由来価格に差し替えられます
（想定優先度: 1. 家庭の実購入価格 → 2. 最新の店舗Web価格 → 3. 過去の店舗Web価格）。
`data/products.js` は次で再生成できます:

```
python3 -c "import json; d=json.load(open('data/products.json')); open('data/products.js','w').write('window.__PRICE_DB__ = '+json.dumps(d,ensure_ascii=False,separators=(\",\",\":\"))+';')"
```

商品画像はDBに存在しないため、絵文字＋色による**識別用プレースホルダー**（`data-visual="placeholder"`）を
生成しています。`js/visuals.js` の `imageUrlFor()` が実画像URLを返すようにすれば差し替え可能です。

## ファイル構成

```
index.html        エントリーポイント
css/style.css     全スタイル（レスポンシブ・アニメーション）
js/data.js        データ層（JSON読み込み・正規化・売場・最小財布判定）
js/coins.js       実在硬貨ロジック（財布構成・おつり・支払いガイドDP）
js/visuals.js     代替ビジュアル生成
js/audio.js       WebAudio効果音（ピッ・チャリン・コトン等）
js/game.js        ゲーム本体（全画面・ドラッグ操作・演出）
data/products.json  価格DB（唯一の価格ソース）
data/products.js    file:// フォールバック（自動生成）
```

## 価格分布（このDBの現実）

150商品中、100円以下は**15商品だけ**（10円以下: 0 / 30円以下: 2 / 50円以下: 5 / 80円以下: 9）。
「100円玉を持っていても棚のほとんどが買えない」──この偏りこそが教材です。
