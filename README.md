# かげに にじの おうかん

4歳児むけの モバイルWebゲーム。
きりに じぶんの かげを だして、あたまに にじの わを つけよう。

雲の上の展望台で、背後からの太陽が前方の霧へ影を落とす。
影の頭のまわりに虹色の輪（glory 風の光学現象）を「育てる」遊びです。

## あそびかた

一度に一つの操作だけ。

| 場面 | 操作 | おきること |
| --- | --- | --- |
| きりを あつめる | 指でドラッグ | 霧が寄ってきて、影がはっきり見える |
| よこに うごく | 左右にスワイプ | 太陽・自分・影の向きが合って、淡い光輪が現れる |
| きりを こくする | 長押し | 輪が二重・三重に育ち、虹の王冠になる |

失敗も採点もありません。近づくほど、影・光輪・色がなめらかに強くなります。
迷っても、霧はひとりでに集まり、ぴったりの位置はゆっくり近づいてきます。

毎回、空の色・雲海の形・輪の太さと数・立つ場所が少しずつ変わります。
ときどき「特別回」になり、光粒と四重の輪が出ます。

## うごかす

ビルド不要の静的サイトです。ES モジュールを使うので、
`file://` ではなく HTTP で配信してください。

```sh
npx http-server -p 8123 -c-1
# → http://localhost:8123/
```

WebGL2 が必要です（iOS 15+ / Android Chrome / デスクトップの主要ブラウザ）。

## つくり

画像アセットはゼロで、絵はすべて Canvas2D で手続き的に生成しています。

```
index.html
css/style.css      画面まわりの UI（縦横両対応、セーフエリア対応）
js/main.js         起動・メインループ・解像度制御
js/scene.js        世界の状態、進行、カメラリグ、位置合わせの計算
js/render.js       描画パス（画家のアルゴリズム順）とインスタンシング
js/shaders.js      GLSL（空・雲カード・霧面・影・虹輪・ブルーム）
js/textures.js     キャラクター・霧・ノイズ・岩場のテクスチャ生成
js/input.js        場面ごとに一つだけ有効なジェスチャ
js/ui.js           ヒント・ビーズ・タイトル・フィナーレ
js/audio.js        風・パッド・チャイム（WebAudio、オン／オフ可）
js/math.js         行列とベクトル
```

### 描画の考えかた

- 深度バッファは使わず、CPU で並べ替えた画家のアルゴリズムで描く
- 霧は複数レイヤーの soft card（インスタンシング、1レイヤー1ドローコール）
- 影は霧の斜面へ投影した四角形にシルエットを貼り、距離で LOD をぼかす
- 虹輪はカメラ向きの板に手続き的な同心バンドを描く。中心ほど明るく、
  細い色帯、柔らかな霞、霧による部分的な隠れを入れる
- Mie 散乱は計算しない。太陽・カメラ・キャラクターの位置関係から
  ずれ量を求め、輪の不透明度・彩度・本数を連続的に動かす
- ブルームは 1/4 解像度で 2 パス。高速点滅はなく、輪は静かに呼吸する

### 性能

- devicePixelRatio は 2 まで、総ピクセル数は約 200 万で頭打ち
- フレームが重い端末では描画スケールを自動で下げる
- WebGL2 baseline のみ。拡張機能や浮動小数点テクスチャは不要
