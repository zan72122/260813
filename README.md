# みずのまち

机の上のミニチュア都市に雨をふらせて、**水のいきさきを変えてあそぶ**実験ゲーム。
4歳児（文字が読めない子）向け。iPhone / iPad の Safari を想定。

災害のこわさを見せるゲームではありません。おもちゃの街と水の実験です。

## あそびかた（文字はいっさい出ません）

```
かわいた街を見る
  → ▶ をおす      … 雨雲が来て、同じ雨がふる
  → 見る           … 一滴 → 細い流れ → 合流 → 水たまり → 越流
  → ■ でとめる
  → ひとつだけ変える … 詰まった排水口をタップ / 大きな排水口のふたを開ける / 壁を指でひく
  → ↺ でリセット   … 街はかわいた最初の状態へ（変えた所はそのまま）
  → ▶ をおす      … まったく同じ雨
  → くらべる       … まえ / いま の 2 まいで、濡れた所のちがいを見る
```

「小さな 1 操作で、街中の水の行き先が変わった」と分かることが中心です。
同じ街を何度でも実験できます（ステージクリア型ではありません）。

### 3 つの介入

| | 何が起きるか |
|---|---|
| 詰まった排水口をそうじ | 葉っぱが飛び、渦を巻いて水が吸いこまれる。ひろばの水が引き、地下入口が守られる |
| 大きな排水口のふたを開ける | ひろばへ着く前に水を横取りする |
| 防水壁を指でひく | 水が壁に当たって左右へ分かれ、別の道路が濡れる |

## 街のしくみ

* 道路は「かまぼこ型」＝まんなかが高い → 両側のみぞに細い流れができる
* 交差点はたいらで低い → 4 本の流れが合流する
* ひろばは街でいちばん低いおわん。入口は 2 か所だけ（＝壁で止められる）
* 地下入口は、ひろばの中の穴。**まわりのふちを水面が越えたときだけ**入る
* 排水口が飲んだ水は地下管を通って川へ出る（断面カットで見せる）


### 水のあつかい

96×96 の height field 上で virtual pipe 法（Mei らの方式の簡略版）を解きます。
物理の正しさではなく、**4歳児に見える因果**をこわさないことを優先しています。

* 高い所から低い所へ / 壁に当たると回りこむ / 穴へ吸いこまれる / 流れ同士が合流する
* 水は 96×96 のビットマップ（3 倍解像度）に描いてから、アイソメへ 1 回で転送
* 浮遊物（葉・花びら・ボール）が流れの向きを見せる

### 「まったく同じ雨」

くらべる遊びなので、再現性は絶対条件です。

* 乱数は固定シードの xorshift のみ（`Math.random()` はゲーム中に一度も使いません）
* シミュレーションは 1/60 秒の固定ステップ。フレーム落ちしても結果は変わりません
* `resetWater()` は水だけを消し、介入（排水口の状態・壁）は残します

単体テストで「同じ条件 → 同じ数字」を、E2E で「1 回目と 2 回目がビットレベルで一致」を
それぞれ守っています。

## モバイルでの配慮

* 縦横どちらでも遊べる。たて長のときは見おろし角を急にして街を大きく見せる
* ボタンはすべて 44pt 以上、下段に固定（safe-area 対応）
* 実ピクセル数に上限を置き、フレームが重い端末では解像度を自動で少し下げる
* 音は最初のタップまで鳴らさない（iOS の制約）。ミュートボタンあり

> フレームレートと最終的な見た目は、GPU のある実機で確認してください。
> ヘッドレス（CPU ラスタライズ）の数字は目安になりません。
