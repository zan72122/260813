# すなのおしろまで かわをつなげる

砂に道を掘って、水をお城まで流す — 4歳児向けの、iPhone / iPad の Safari で
そのまま遊べる WebGL の砂場ゲーム。

指で砂をなぞると、その軌跡がそのまま川の道として残る。水差しを押している
あいだだけ水が出て、水は自分の掘った溝を進む。逸れたら砂を盛って直せる。
最後にお堀が満ちると、水車が回り、跳ね橋が下り、旗が上がる。

失敗はない。制限時間も、点数も、星も、ゲームオーバーもない。

## 遊びかた（文字を読まなくてよい）

| 道具 | すること |
| --- | --- |
| シャベル | 砂をなぞって溝を掘る |
| スコップ | 砂を盛って水をせき止める |
| 水差し | 押しているあいだ水を注ぐ |

一本指だけ。ピンチもカメラ操作も不要。3〜5 秒迷うと、道具が揺れ、砂場のアヒル
がつぎに触るところを見る。

## 動かす

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # 型検査 + 本番ビルド
npm run test:e2e   # Playwright（Chromium）
```

`?e2e=1` を付けると軽量モード（DPR 1、影なし、粒子削減）で起動する。

## つくり

- **Vite + TypeScript + Three.js**、WebGL 2。バックエンドも外部通信もない。
- **砂** — 121 × 51 の height field。頂点ごとに `height` / `wetness` /
  `compaction` を持ち、書き換わった矩形だけを GPU へ再アップロードする。
  掘った深さと元の高さの差を陰影と湿りに変換しているので、水が来る前から
  「掘れた」ことが見える。
- **水** — 仮想パイプ方式の簡略浅水モデル（`src/game/water.ts`）。パイプ断面は
  水深に比例するので、深く掘った溝ほど多く流れる。厳密さより、
  「低い方へ流れる」「溝へ入る」「せき止められる」「たまる」「あふれる」が
  目に見えることを優先している。
- **カメラ** — 自由操作なし。砂場の四隅を実際に射影して、道具トレイと設定
  ボタンを避けた空き領域にぴったり収まる俯角と距離を数値的に解く
  （`src/render/cameraRig.ts`）。縦画面は手前から奥へ、横画面は左から右へ
  水が流れる。指を置いているあいだカメラは動かない。
- **道具** — ピクセル座標の正射影オーバーレイに 3D モデルを描いている。
  端末によらず指の当たり判定が十分大きい。
- **音** — すべて Web Audio の合成音。最初のタッチで unlock する。
  音量ゼロでも視覚だけで理解できる。

## 確認済みの範囲

`e2e/` に入っている。

- `causality` — 水が溝を選ぶ／砂を盛ると流れが変わる／穴にたまり堤防で止まる
- `playthrough` — 縦・横それぞれで、掘る → 注ぐ → 流れる → お堀が満ちる
- `loop` — 結果を数秒見せてから絵のメニューが出て、1 タップで再開できる
- `robust` — 連打、途中で指を離す、逆方向ドラッグ、砂場の端、水の出しすぎ、
  画面回転、バックグラウンド復帰、スクロール暴発
- `menu` / `settings` — 4 サイズでの当たり判定、音量と「動きを弱くする」の保存、
  シミュレーション更新のフレーム予算
