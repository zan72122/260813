# おかいものシアター

イオン具志川店（イオン琉球ネットスーパー）の**実在商品・実売価格**だけを使った、
4歳児向けの3Dおかいもの体験ゲームです。

商品カードをクリックするゲームではありません。
**現実の買い物に存在する一連の身体動作**——入店・カートを取る・売場へ歩く・
棚から商品を手に取る・値札を見る・カゴへ入れる・レジへ運ぶ・店員が1つずつ「ピッ」と
スキャンする・100円玉を渡す・おつりを受け取る・レシートをもらう・袋詰めする・
カゴを返す・退店する——そのものを遊びにしています。

> **本作はイオン株式会社・イオン琉球株式会社の公式アプリではありません。**
> 公開されている店頭価格を教材として利用した非公式の教育用ゲームです。

## あそびかた

ブラウザで `index.html` を開くだけです（ビルド不要・外部通信なし・オフライン動作）。

```
python3 -m http.server 8000   # 推奨（file:// 直開きでも動作します）
# → http://localhost:8000/
```

iPhone / iPad の縦・横画面両対応。操作はタップとドラッグのみ。

## シアター方式

「意味のある操作は子どもが行い、つなぎの動作はキャラクターが演技する」方式です。

- 子どもが行う操作：ドアをタップ／カートを取る／商品を棚からカゴへドラッグ／
  カゴをレジ台へ置く／（予算オーバー時）戻す商品を店員へ渡す／100円玉をトレーへ／
  おつりを財布へ／レシートを取る／商品を袋へ詰める／カゴを返却する
- キャラクターが演技する部分：店内の歩行（カート押し・車輪回転・カメラ追従）、
  店員のスキャン動作（商品を取る→回してバーコードを探す→「ピッ！」→済みカゴへ）
- カメラはプレイヤーが操作せず、場面ごとに最適な位置へ自動移動します
  （移動中は後方追従、棚では正面、スキャンは手元、支払いはトレー、袋詰めは俯瞰）

## Vertical Slice（現在の実装範囲）

「一回の買い物を最後まで面白くする」ことを最優先し、お菓子棚1台・実価格6商品で
入店から退店までを完結させています。

| 商品（DBから選定） | ゲーム価格 |
|---|---|
| やおきん うまい棒チーズ味 | 16えん |
| 菓道 もろこし輪太郎 | 32えん |
| 有楽製菓 ブラックサンダー | 43えん |
| バンダイ つりグミ スーパーマリオ | 86えん |
| スウィーフィー ミックスゼリー | 95えん |
| カルビー ベジたべる あっさりサラダ味 | 100えんより たかい（実価格170円） |

- 予算は100円（100円玉1枚）。**予算を超える商品もカゴに入れられます**
- 足りないと分かるのはレジ。店員が「100えんより たかくなったよ。どれを もどそうか？」
  と聞き、子どもは商品の優先順位を自分で決めます（失敗扱い・減点なし）
- 全部戻して「なにも買わない日」も正しく完結します（100円玉がそのまま残る体験）

### 設計ルール

- 価格はDBの `game_price_yen` のみ。丸め・値引き・架空商品・架空価格は一切なし
- 100円以下は実数表示、**101円以上は「100えんより たかい」**（子ども画面に101以上の数字を出さない）
- 硬貨は実在の1・5・10・50・100円のみ。おつりも実在硬貨の物理的な受け渡し
- 時間制限・スコア・警告音・赤い×なし

## 技術構成

Three.js（`vendor/three.min.js`、UMD・オフライン同梱）による本物の3Dシーン。
DOMは所持金・短い台詞・ヒント・一時ボタンの最小HUDのみ。

- Low-poly プリミティブ＋canvasテクスチャ（外部アセットなし）
- 商品は形状タイプ（stick / pouch / bar / box / cup / bigpouch…）を再利用し、
  絵文字＋短縮名ラベルで識別（将来実パッケージ画像へ差し替え可能な構造）
- 影なし（擬似ブロブ影）・Lambert材質・共有マテリアル・低draw-call
- 効果音はWebAudio合成（ドア「ウィーン」・車輪・「コトン」・「ピッ」・「チャリン」・
  レシート・袋「カサッ」・カゴ「カコン」）
- アイドル演出：店員の揺れ・遠くを歩く客・冷蔵ケースの光・レジランプ・看板の揺れ

```
index.html            おかいものシアター（メイン）
js/theater/world.js   舞台装置（店・棚・商品・人物・レジ・サッカー台）
js/theater/game.js    演出・進行・入力・カメラ
vendor/three.min.js   Three.js r149（同梱）
classic.html          旧2D版（スキャナー/100えんライン/どのおかね/価格図鑑/親モード）
css/coins.css         実在硬貨の共有スタイル
js/data.js            データ層（価格DBの読み込み・正規化）※両版共通
js/coins.js           硬貨ロジック（おつり・支払い組合せ）※両版共通
js/audio.js           効果音 ※両版共通
data/products.json    価格DB（唯一の価格ソース・イオン具志川店 2026-08-13）
data/products.js      file:// フォールバック（自動生成コピー）
```

## データ層

商品データはコードから分離されています。`data/products.json` を同スキーマのJSONに
置き換えるだけで他店舗・別日・家庭のレシート由来価格に差し替えられます
（想定優先度: 1. 家庭の実購入価格 → 2. 最新の店舗Web価格 → 3. 過去の店舗Web価格）。

棚に並べる商品は `js/theater/game.js` の `SHELF_PLAN`（商品名マッチ＋形状タイプ）で
選定され、DBに該当が無い場合は「安い商品＋100円超商品を必ず混在させる」フォールバックで
6点を自動選定します。

`data/products.js` の再生成:

```
python3 -c "import json; d=json.load(open('data/products.json')); open('data/products.js','w').write('window.__PRICE_DB__ = '+json.dumps(d,ensure_ascii=False,separators=(\",\",\":\"))+';')"
```
