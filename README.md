# よるのうみ — 生物発光する夜の海

4歳児向けの iPhone / iPad モバイルWebゲームです。
「くらい海を動かすと、青い光が出る」——それだけを、ていねいに。

## あそびかた(文字の説明は画面に出ません)

1. 夕方の入り江。研究者がランタンを指さします
2. ランタンを**下へスワイプ**すると明かりが消え、夜になります
3. 真っ暗な水面を**指でなぞる**と、そこだけ青い光が生まれます

- **トン、とタップ** → 小さな星のような光
- **ゆっくりなぞる** → 細長い光の川
- **大きく円を描く** → 渦を巻く光
- **まっすぐ大きくスワイプ** → パドルの航跡。ボートが進み、両脇に光の筋
- 何度かパドルを漕ぐと、一度だけ静かな「ごほうびの光景」が訪れます
  (水面いっぱいの光の連鎖、光る魚の群れ、星空の水鏡)
- そのあとは、まるいボタンでもういちど

失敗も点数も制限時間もありません。

## 実行方法

静的ファイル1枚だけです。任意の静的サーバで配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/index.html を iPhone/iPad の Safari で開く
```

※ WebGL2 が必要です(iOS 15+ / モダンブラウザ)。file:// 直接オープンでも動作します。

## 技術メモ

- 依存ライブラリなし。単一 `index.html`(WebGL2 + 2D canvas オーバーレイ)
- タッチ軌跡は半解像度の **trail texture**(RGBA16F、非対応時はRGBA8)へスタンプ書き込みし、
  毎フレーム減衰・拡散。ミップマップをブルームとして再サンプル
- 発光粒子は CPU 更新の GL_POINTS(最大数千、フレーム時間により自動増減)
- 波紋はシェーダ内の解析的リング、波頭・星の水鏡・月・空グラデーションも合成シェーダ内
- ボート・研究者・ランタン・魚のシルエット・UIヒントは 2D canvas
- `pointermove` + `getCoalescedEvents` で低遅延追従。発光は指先の少し上に出して指の遮蔽を回避
- 縦横回転・リサイズ対応。フレーム時間の移動平均で品質(解像度スケール/粒子上限)を3段階自動調整
- テスト用フック: `window.__biolume`(fps / particles / phase / skipIntro() など)
