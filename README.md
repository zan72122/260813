# スクランブルこうさてん 🚦

4歳児向けのスクランブル交差点・群衆シミュレーション遊び。
iPhone / iPad のブラウザで動く、インストール不要の1ファイルゲームです。

大人が都市計画でやる「歩行者流シミュレーション」の本質を、

1. 四隅に人がどんどん溜まる（赤信号）
2. しんごうボタンを押すと **150人が一斉に解放** される
3. 中央で人の川が交差して「ぎゅうぎゅう」になる
4. とめて、**道路をひとつだけ変える**
5. もどして、**同じ150人でもう一度**流す
6. 人の川の形が変わる！

という Tiny Scientist Loop に変換しています。

## 遊び方（ぜんぶ一本指）

| そうさ | なにがおきる |
|---|---|
| 🔴 しんごうボタンをタップ | 青になって、みんな一斉にわたる |
| 🟡 黄色いまるをドラッグ | 横断歩道が広くなる／狭くなる |
| あおのながさ ボタン | 青信号が「みじかい」⇔「ながい」 |
| ⏸ とめる / ▶ うごく | シミュレーションの一時停止 |
| ↩ もどす | 同じ150人が同じ場所に戻る（同条件リプレイ） |

数字やスライダーは出てきません。混雑は「人だんご」「床の赤いにじみ
（密度ヒート）」「よろよろ歩き」で、改善は「スイスイ流れる川」で見えます。

## 実行

```bash
npm run serve        # http://127.0.0.1:8734/index.html
```

静的ファイルのみ（Three.js は `lib/` に同梱）。任意の静的サーバで動きます。

## しくみ

- `src/sim.js` — 描画に依存しない純粋JSの群衆コア。
  固定タイムステップ + seed付き乱数で**完全決定論**（RESETすると同じ人が
  同じ動きをやり直すので、介入の効果だけが差分になる）。
  - flow-field的な「自分のゲート→出口ゲート」コリドー追従
  - social-force風の軽量近傍回避（spatial hash、剛体衝突なし）
  - 密度による減速、対向流の車線形成バイアス、縁石ファネル
  - 横断歩道の幅が「入口の掃け速度」と「帯内の密度」に直結
- `src/main.js` — Three.js 描画。歩行者は InstancedMesh 4つ
  （体・頭・帽子・丸影）で150人でもドローコールは一定。
  カメラは固定アングルの自動演出（解放時に引き、混雑時に寄り、
  介入時は俯瞰、リプレイ時は同構図に復帰）。
- 密度ヒートは20×20グリッドを頂点色で描く加算ブレンドの板1枚。

## 検証

```bash
npm run verify   # Node上でシナリオ検証（混雑・取り残し・介入効果・決定論）
npm run test:e2e # Chromium スモークE2E（決定論APIで論理時間を直接進める）
node tools/shots.mjs        # 主要シーンのスクリーンショット
node tools/interactive.mjs  # タップ/ドラッグの実操作フロー検証
```

代表的な計測値（seed 42・150人）:

| シナリオ | 渡れた | 取り残し | ピーク混雑 | 混雑量 |
|---|---|---|---|---|
| baseline（狭い・青みじかい） | 137 | **13** | **90人** | 489 |
| 横断歩道を広げる | 150 | 0 | 33人 | 172 |
| 青をながくする | 150 | 0 | 90人 | 537 |
| 両方 | 150 | 0 | 32人 | 206 |

介入ごとに効く問題が違う（幅→混雑、青→取り残し）ので、
「今度はどこを変える？」の再実験動機が生まれます。
