# ぺちゃっ！ぎゅっ！ぺりっ！ のりこうじょう

4歳児向けのモバイルWebゲーム。iPhone / iPad の Safari で遊べます。
黒緑のどろどろを、混ぜて・流して・均して・押して・乾かして・ぺりっと剥がすと、
見慣れた四角い海苔になります。**画面に文字は一切出ません。**

## 遊び方（大人向けの説明）

| 工程 | 操作 | 起きること |
| --- | --- | --- |
| 1 まぜる | 桶の上を指でぐるぐる | どろどろが渦を巻く |
| 2 ながす | ひしゃくを枠の上へドラッグ | 黒緑の液が枠に落ちる |
| 3 ならす | 枠の上を左右にスワイプ | 面が四角く均一になり、水が下へ落ちる |
| 4 みずをぬく | スポンジを押しあてる | 端から水がにじみ出て、面が締まる |
| 5 かわかす | レバーを下へ引く | 送風機が回り、色が濃く・艶が減る |
| 6 ぺりっ | 手前のふちをつまんで引く | 乾いた海苔が音を立てて剥がれる |
| 7 できた | （自動） | 海苔が重なり、おにぎりに巻かれ、お弁当になる |

制限時間なし、ゲームオーバーなし、後退なし。数秒迷うと次に触る対象が揺れて光ります。

## 起動

```bash
npm start          # http://localhost:5173/
```

依存パッケージなしで動きます（ビルド不要・アセットなし・全部Canvas 2Dの手続き描画）。
実機で試す場合は、同じ Wi-Fi 上で起動時に表示される LAN の URL を iPhone / iPad で開いてください。

## 自動試遊（検証）

Playwright（`playwright` パッケージ）が必要です。

```bash
npm start &                     # サーバを起動しておく
npm run playtest portrait       # 縦画面で一周プレイ + 各工程のスクショ
npm run playtest landscape      # 横画面で一周
npm run playtest ipad           # iPad 横で一周
npm run preview portrait        # 各工程の見た目だけ素早く確認
```

`playtest` は実際のポインタイベントを流して最初から最後まで自走し、
途中で画面を回転させて状態が壊れないことを確認し、`shots/` に各工程の画像を保存します。
ページエラーがあれば異常終了します。

## 構成

```
index.html        画面と iOS 向けの設定（拡大・スクロール・タップ遅延の抑止）
server.js         依存ゼロの静的サーバ
src/main.js       ループ、ポインタ入力、回転対応、テスト用フック
src/game.js       工程のステートマシン、カメラ、誘導、剥がしの物理
src/sheet.js      海苔シートのモデルと描画（どろどろ→面→乾き→剥離）
src/scene.js      工房・桶・抄き枠・道具・おにぎり・お弁当
src/layout.js     縦横それぞれの「再構図」とカメラ矩形
src/fx.js         水滴・しぶき・湯気・きらめき
src/audio.js      WebAudio による効果音の合成（音声ファイルなし）
src/util.js       数学・ノイズ
```

### 設計メモ

- **状態は正規化グリッド**（0..1 × 0..1）で保持しているので、画面を回しても製造中の海苔は壊れません。
- **縦横は単なる回転ではありません。** 縦は「桶が上・枠が下」、横は「桶が左・枠が右」と、
  ワールド配置そのものを組み替えています（`src/layout.js`）。
- **剥がし**は、ヒンジを原点・指の方向を真下とするローカル空間で円弧として解いています
  （材料長 L が弦 d に収まるときの曲率半径 R を二分法で求め、`y = R sin(弧長/R)`）。
  行を曲線に垂直に回さないので、幅の広いシートでも扇状に割れません。
- **背景はワールド空間に一度だけ焼いて**毎フレーム貼るだけにしています。
