# ぱらっ！ふわっ！丸亀うちわ工房

4歳児（主に女児）向けの、モバイルWebゲーム。
香川県丸亀市の伝統工芸「丸亀うちわ」を、**一本の竹から**作る。

看板動作は **「一本の竹 → パラパラ → 扇状の骨」**。
切込みの入った竹を指で左右へ動かすと、竹骨が一本ずつ、
パラッ、パラッ、と分かれ、最後にファサッと扇状へ広がる。

最後は完成したうちわを自分で振り、風鈴・風車・紙飾り・木の葉が
指の速さに応じて揺れる。

## あそびかた

指1本だけ。ピンチも2本指回転も使わない。
失敗なし、ゲームオーバーなし、時間制限なし、点数なし。

| 工程 | 動作 |
| --- | --- |
| 1 たけ | タップ |
| 2 わる | 竹の上を下へなぞる |
| 3 **パラパラ** | 指を左右へ動かす（看板動作） |
| 4 ゆみだけ | 左から右へドラッグ |
| 5 いと | 骨の上をジグザグになぞる（糸色5種） |
| 6 そろえる | 端を外側へドラッグ |
| 7 のり | 刷毛でなぞる |
| 8 わし | 柄を選ぶ→下ろす→中央から外へ撫でる（柄6種） |
| 9 たたく | 木づちをトントン |
| 10 へり・ローラー | 縁をなぞる→上から下へ転がす |
| 11 かぜ | うちわを左右に振る |

タイトルと完成画面から **「パラパラだけ」** の自由モードに入れる。
竹の色・広がり方・開く順番・糸色が毎回変わる。

## 実行

```sh
npm install
npm run dev       # http://localhost:5173/
npm run build     # 型検査 + 静的ビルド → dist/
npm run preview
```

`dist/` は完全な静的ファイル。任意の静的ホスティングに置ける。

## 技術構成

- **Vite + TypeScript**、依存ライブラリ 0（実行時）
- **自前の軽量3Dレンダラ**：透視投影（ピンホールカメラ）＋ペインタ順で
  Canvas2Dへ描画。竹骨は毎フレーム手続き生成する帯ジオメトリ。
- **アセット 0**：テクスチャ（竹繊維・和紙繊維・6種の和柄・木目）は
  起動時にCanvasで手続き生成。効果音はWebAudioで合成。
  ビルド成果物は gzip 約27KB。
- **カメラ**：各工程が「画面に必ず収めたいワールド境界」を宣言し、
  カメラ側が距離とFOVを解いて縦横どちらでも収まるようにする。
  CSSの拡大縮小ではなく、縦横で構図そのものが変わる。

### 「パラパラ」の実装

竹骨 i ごとに開き量 `t_i ∈ [0,1]` を持つ。
指の移動量を `energy` に積み、

```
t_i = clamp(progress - rank_i, 0, 1)
progress = (0.18·e + 0.82·e^1.35) · N        （e = energy）
```

で 1本 → 3本 → 6本 → 10本 → 一気に、と加速して開く。
骨上の点は、閉じた姿勢（円柱面上）と開いた姿勢（扇平面）を
`b(u) = smoothstep((u - (1 - t_i)) / 0.34)` で補間するので、
**裂け目が先端から根元へ向かって進む**。
さらに指の速度が各骨のバネに入り、開いていない間も指へ1:1で反応する。

全部開いた瞬間に `bloom` へ 1.15 を入れ、バネで揺り戻す（ファサッ）。
同時に短いスローモーション、画面シェイク、フラッシュ、
20本ぶんの効果音を重ねる。

## 検証用スクリプト

```sh
node tools/play.mjs      # VP=iphone-p|iphone-l|ipad-p|ipad-l 全工程を自動プレイ
node tools/verify.mjs    # 受け入れ確認（音の解錠／パラパラ10連／縦横の見切れ）
node tools/robust.mjs    # 連打・逆スワイプ・回転中操作などの耐久確認
```

いずれも `npm run dev` を起動した状態で実行する。
