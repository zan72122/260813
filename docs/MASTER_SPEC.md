# MASTER_SPEC — 笛が鳴ったら、お水の番！― ベルサイユ噴水職人

対象: iPhone / iPad の Safari で遊ぶ 4歳女児向け短編モバイルWebゲーム。
子ども文: 「笛を鳴らして、くるくる回すと、王さまの前でお水が出る。」

## 看板となる固有動作鎖（絶対に分断しない）

王の進行を見る → 笛を鳴らす → 特殊バルブへカメラが寄る → 時計回りにバルブを回す
→ 配管内を水が走る → 王の進路上の噴水だけが突然噴き上がる

これは ON ボタン＋成功ムービーではない。指の円運動・バルブ回転・水の移動・噴水発生を
**連続した一つの因果**として知覚させる。回す速さが水圧の立ち上がりに反映され、
指を止めればレンチも水も止まる。

## ゲームループ（一周 75〜120 秒）

| # | Phase (GamePhase) | 主動詞 | 内容 |
|---|---|---|---|
| 0 | `title` | 触る | タイトル一枚。タップで開始（audio unlock を兼ねる） |
| 1 | `garden-idle` | 見る | 朝の静かな庭園。王の進行 = 金の太陽印の行列が進む |
| 2 | `whistle-cue` | 鳴らす | 王が次の噴水へ近づくと笛が揺れる。タップ/短長押しで笛音。連打は音を重複させない（cooldown + pitch制御） |
| 3 | `valve-approach` | 見る | カメラが庭園を見失わずバルブ機構部へ寄る（連続移動） |
| 4 | `valve-turn` | 回す | 一指の円運動でレンチを時計回りに回す。openness 0→1 |
| 5 | `pipe-run` | 見る | 連続カメラ or <0.5s 移行で配管 cutaway。光る水塊が走る |
| 6 | `fountain-reveal` | 見る/喜ぶ | 水と共に地上へ抜け噴水が上がる。成功状態を最低1.5秒見せる |
| 7 | （2〜6 を噴水3基分繰り返す） | | 各噴水で形・音・Revealカメラを少し変える |
| 8 | `finale` | 見る/喜ぶ | 三噴水が一度だけ同時に動く。水霧に淡い虹可 |
| 9 | `replay-choice` | 選ぶ | 絵の三択: もう一度同じ噴水 / 最初から / 自由にバルブ。二タップ以内で再プレイ |

## 三つの噴水

| id | 水形状 | Reveal の差別化 |
|---|---|---|
| `fountain-fan` | 扇形 | 低い水面近くから見上げ、扇の開きを追う |
| `fountain-ring` | 円環 | 円環の外周を軽く回り込む |
| `fountain-crown` | 中央高噴流＋低い周囲噴流 | 中央噴流の立ち上がりを縦に追う |

操作文法（笛→寄る→回す→水→Reveal）は3基とも同一。

## バルブ操作仕様（核心）

- 一指の円運動。中心から外れても角度追跡で補正（タッチ点とバルブ中心の角度差分を使う）
- 時計回りのみ開く（史実準拠）。反時計回りは失敗にせず、軽い抵抗表現＋弱い円形誘導で時計回りへ吸着
- 角速度 → 水圧立ち上がり速度へ穏やかにマップ（ローパスで平滑化）
- 指を止める → レンチ停止、水圧上昇も停止（openness は保持、減らない）
- openness がしきい値（1.0）に達したら pipe-run へ

## 子どもUX必須要件

一指操作 / 大きな当たり判定（最小 88px 相当）/ 強い軌道補正 / 3〜5秒無操作で非言語ヒント
（笛が光って揺れる、レンチ周りに円形の光の軌跡など）/ ゲームオーバー・制限時間・点数・破損なし。
一 scene に主動詞は一つだけ。原因と結果が成立する瞬間はカメラを切らない。文字による指示は使わない。

## 技術方針

- Vite + TypeScript strict + Three.js。static web app。backend / login / 広告 / 分析 / 課金なし
- モバイルSafari第一。WebGL2 で中核成立。WebGPU は使わない（追加品質のみ許可だが本作は対象外）
- real fluid simulation 禁止。tube geometry + animated shader + 少量 particle で偽装
- DPR 上限 (例: min(devicePixelRatio, 2))、影を落とす光源は1つ、texture ≤2048px（原則1024px以下）
- resize / orientation change で scene を破壊せず、GamePhase と openness を保持
- 最初のユーザー操作で AudioContext を unlock。全音源は Web Audio で手続き生成（外部音源不使用）
- タッチ中の scroll / selection / double-tap zoom を防止
- dispose 漏れ、animation loop 重複、listener 重複を防ぐ
- Reduce Motion 対応・光を弱くする設定・mute を DOM UI（絵アイコン）で提供

## 品質予算（目標値。画質を壊して数字合わせしない）

主scene draw calls ≤120 / 同時 triangle ≤250k / 同時 particle ≤1500 /
高価な render pass は必要最小限（水面反射は planar 1枚 or 環境マップ偽装）/
console error 0 / 未処理 rejection 0

## 非目標

- 自由カメラ・自由移動・オープンワールド
- 精密人物モデリング（王は金の太陽印＋簡略行列表現）
- 文字による説明・チュートリアル
- スコア・失敗・タイマー・収集要素
- 実写質感の人物劇 / 汎用AIファンタジー / 子どもアプリ風平面アイコン集
- 外部アセット（画像・3D・音源）の取り込み。全て手続き生成
