# STAGE_MECHANISM_ABSTRACTION — 地下機構の可視化モデル

本ドキュメントの機構は docs/HISTORICAL_TRUTH.md の P1〜P5（Plausible abstraction）である。
実在の王妃の劇場の機構配置を主張しない。幼児が因果を追える最小構成に整理する。
本格cloth / rope / rigid-body simulationへの依存は禁止。すべてprogress駆動の決定的計算。

## 構成部品（これ以上増やさない）

1. **太い麻ロープ**（spline/tube、1本）: 子どもが引く対象。地下の手前に垂直に垂れる。指より少し横に表示。
2. **ロープロック**（1個）: ロープを噛む木製レバー。unlock phaseでタップ/短スワイプ→「カチン」と跳ね上がる。
3. **大滑車**（2個）: ロープの向きを変える。ロープ移動量に比例して回転。
4. **木製巻上ドラム**（1個、横軸）: ロープを巻き取る主動輪。回転が全装置の駆動源に見えること。
5. **カウンターウェイト**（1個）: ドラム脇で上下する石/鉄の錘。「重いものが機構を助ける」の絵解き。
6. **チャリオット（袖カート）**: 地下の溝を走る小さなカートが各袖flatの根元に接続。上の袖が動く因果を地下でも見せる。

## progress → 各要素の決定的マッピング（純関数）

`p = StageTransformProgress ∈ [0,1]`、遷移ペア (fromScene, toScene)。
全要素は `f(p)` のみで決まる。個別timer・遅延tween禁止（指を止めた瞬間に全停止するため）。

| 要素 | マッピング |
|------|-----------|
| rope travel | ropeOffset = p × ROPE_TOTAL_TRAVEL(≈2.4m)。tubeのUVスクロール＋把持点移動。 |
| pulley回転 | θ = ropeOffset / pulleyRadius |
| drum回転 | θ = ropeOffset / drumRadius |
| counterweight | y = lerp(y0, y1, p) |
| chariot | 旧袖カート: x外側へ p∈[0,0.9]で退場。新袖カート: x内側へ p∈[0.1,1.0]で入場。 |
| 旧舞台袖(3対) | 奥の対から順に退場: 対i(i=0奥)は p∈[0.05+0.1i, 0.55+0.1i] で舞台外へスライド。 |
| 新舞台袖(3対) | 手前の対から順に入場: p∈[0.25+0.1i, 0.75+0.1i]。旧と新が擦れ違う瞬間を作る。 |
| 背景(backdrop) | 旧背景が上へ巻き上がり(p∈[0.3,0.8])、新背景が背後から現れる。巻き上げは平面のスケール/位置＋巻き軸円柱で表現（cloth禁止）。 |
| 前景props | 旧: p∈[0.1,0.4]で床下へ沈む。新: p∈[0.6,0.95]でせり上がる。 |
| 照明ブレンド | 色温度・強度を smoothstep(0.35, 0.9, p) でfrom→toへ。 |
| 機構音 | ピッチ/密度は dp/dt（引く速度）に比例。停止で消音。詳細はCONTRACTSのAudioCue。 |

区間定数は `TRANSFORM_TIMELINE` として一箇所に定義し、gameplay-cameraとrendering-audioが共有する
（定義場所は src/core/ の契約、変更はIntegratorのみ）。

## ストローク仕様（入力→p）

- 下ドラッグのY移動量 dy(px) → dp = dy / (viewportHeight × 0.6) × 0.35
- 上ドラッグは同式で負方向。斜めはY成分のみ。
- p>0.97→1.0スナップ（音: コトン thud）。p<0.03→0.0スナップ（軽い解放音）。
- スナップ直前の見かけ速度をわずかに減速（easing）してよいが、指を止めれば即停止が優先。

## 「単純クロスフェード禁止」の実装定義

- 景の交換は**rigid painted flatsの物理的移動**（スライド/巻き上げ/せり）で行う。
- material opacityの全画面フェードで景を切り替えることは不合格。
- 照明ブレンドのみopacity/色補間を許可（装置自体は動きで交換）。
- 検証: progress 0.5静止時、旧袖と新袖が**同時に舞台上に見えている**こと（E2Eスクリーンショットで確認）。

## 貫通・ちらつき対策

- 袖flatsのZオフセットを対ごとに5cm刻みでずらし、z-fighting回避。
- 退場済み装置は舞台外で非表示化してよい（draw call削減）が、p逆行で即再表示できること。
- scene終了時（p=0/1）に全装置が定位置スナップし、端数誤差を残さない。
