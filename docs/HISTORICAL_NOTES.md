## 本作での翻案（意味と固有動作を保ち、工程を圧縮）

- **クレーンの自己上昇**を看板体験に据える。走行部（runner）と車輪を機体に明示し、「塔の脚のレールを登る」ことが見て分かる造形にする。
- 4本のクレーンは**1台**に圧縮（子どもの視点が分裂しないため）。
- 仮ボルト→熱間リベット置換は「大きな仮ボルト2本 → 赤熱リベット1本のリレー」に圧縮。順序（ボルトが先、リベットが後）は史実通り維持。
- 4人班のリレーは全員成人作業員として描き、**危険作業は大人が実行**、子どもは指でリレーを進める援助役。役割は史実の4役（加熱・受け渡し・保持・打撃）を保つ。
- 部材が「工場から運ばれてくる」ことは、開幕時に地上へ置かれた製作済み鉄骨（荷札付き）として表現。
- 塔の色は建設期の赤褐色系（Venice red〜red-brown）。現代のグレーは使わない。
- 遠景は1889年基準：セーヌ川、オスマン様式の屋根並み、トロカデロ宮。現代建築は置かない。
