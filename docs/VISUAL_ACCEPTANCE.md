# VISUAL_ACCEPTANCE — 視覚合格基準

スクリーンショットのみで判定できるよう書く。判定者は実装説明を読まない。

## 方向性

1888年前後の建設現場。精密な博物館模型と高品質玩具の中間。暖かい午後光。遠景は少し霞んだ1889年のパリ（セーヌ、オスマン屋根並み、トロカデロ宮）。塔は建設期の赤褐色（Venice red〜red-brown）。**現代UI禁止**: neon gradient、glassmorphism、カード羅列、汎用AI風LPは不合格。

## Hero Materials（描画予算の優先順）

1. 鉄骨（赤褐色〜暗鉄色、リベット点列、X格子）
2. 赤熱リベット（emissive 赤→橙→暗鉄色の冷却遷移）
3. 蒸気（柔らかい白のsprite、volumetric禁止）
4. 太いケーブル（spline、張り/弛みが読める）
5. 機械面（油と煤の付いた鉄、真鍮の口金）

## 合格チェックリスト

### Opening（起動3秒以内の静止画で）
- [ ] エッフェル塔（建設途中）と分かる: 曲線脚、X格子、未完の上端
- [ ] 塔の脚に載った小型蒸気クレーンと分かる: 格子ブーム、縦型ボイラー+煙突、蒸気の筋、ケーブルドラム、レール上の走行部
- [ ] 次に取り付ける鉄骨部材、フック、成人作業員が見える
- [ ] パリらしい遠景（川・屋根並み・霞）

### 操作場面
- [ ] フック、鉄骨、目標ghostが互いに重ならず、指で隠れない位置
- [ ] ghost silhouetteが半透明で「ここに置く」と一目で分かる
- [ ] リベットマクロ: 赤熱・打撃・冷却の色遷移が読める
- [ ] 一場面のDOM UIは最大3要素（HUD小物除く）。画面がカードで埋まっていない

### Climb（看板）
- [ ] 低い側面カメラで車輪/runnerとレールが見える
- [ ] 白い蒸気が吹き、格子が近景を通過し、パリ遠景が相対的に沈む
- [ ] 到着前後の比較で塔が一段高くなったと読める

### 全体
- [ ] 縦(390×844, 820×1180)・横(844×390, 1180×820)の4構図全てで重要物が切れない・隠れない
- [ ] 玩具的だが安っぽくない: 単色ベタ+デフォルトマテリアルの羅列は不合格。AO風の陰影、色数の統制、材質差（鉄/真鍮/木/布）が読めること
- [ ] 文字に依存した指示が画面にない（ロゴ的装飾文字は可、操作説明の文章は不可）
