# PRODUCT_SPEC — エッフェル塔をのぼる蒸気クレーン

一文: 子どもが蒸気クレーンで鉄骨を吊り上げ、赤熱リベットで塔へ固定し、一仕事終えるたびにクレーン自身が完成した塔をガチャガチャ登るゲーム。

看板体験は **クレーン自身が自分の作った塔を登る瞬間**。ここに最大の演出予算を割く。

## 対象と制約

- 主対象: 4歳女児。iPhone/iPad、縦横両対応、一指操作、読字不要。
- 1周 3–5分。終了後2タップ以内で再プレイ。
- 失敗・ゲームオーバー・制限時間・点数・星・広告・課金・ログインは存在しない。
- 音を切っても遊べる。文字を全て隠しても一周できる。

## 再プレイメニュー（complete画面、絵のみ）

1. 同じのをもう一回（同一seed）
2. ちがう鉄骨（新seed → 別のBeamShape）
3. リベットだけ遊ぶ
4. クレーン昇降だけ遊ぶ

いずれも2タップ以内で開始。towerLevelはセッション内で累積し、塔が徐々に高くなる（最大表示レベルあり、それ以上は見た目維持）。

## 各フェーズの操作仕様

- **hookDown**: 画面のどこを縦ドラッグしてもフックが追従（レバー領域でなくてよい）。表示は指より上へ約80px offset。鉄骨上端から吸着半径内で自動スナップ→短い連結アニメ→自動でhoistへ。
- **hoist**: 上方向入力速度を0.35倍で穏やかに反映。荷は解析的振り子: `sway(t) = A·sin(ωt)·damp`, 振幅Aは入力加速度に比例、上限±6°。落下なし。
- **align**: ドラッグで荷を水平±縦微調整。ghostとの距離 d に応じ移動ゲイン `g = clamp(d/D, 0.25, 1)`。d < snapR で吸着。許容は非常に広い（snapR = ghost幅の45%）。縦横どちらの構図でも荷とghostが同一視野内。
- **bolts**: 誇張された大きなボルト2本がトレー上。穴へドラッグ、穴の吸着半径は72px以上。順不同。
- **rivetリレー**: 炉(加熱)→トング持ちが受け→穴前へ。右スワイプで次の作業員へ。逆方向スワイプは無害（作業員が首を振るだけ）。危険作業は成人作業員が実行し、子は「指示/援助」する構図。
- **rivetHammer**: 打点anchorをタップ。1打ごとに頭部morph 1/3、火花、打音ピッチ上昇。連打しても3打で確定、二重遷移なし。
- **climb**: 大きなclimb lever(世界内オブジェクト)を上へドラッグ。レバー角に比例して蒸気弁が開き進行。指を離すとレバーは保持位置に留まり進行継続（幼児が離しても破綻しない）。progressは単調増加のみ。

## ソフトロック防止

- 3秒無操作: 対象anchorが「呼吸」拡大(scale 1→1.12、reducedMotion時は明滅なしのハイライト)。
- 5秒無操作: 作業員が対象を指差す/視線誘導 + 手のpictogramが正しいジェスチャを1回演示。
- どのフェーズも誤入力で状態が壊れない。入力は各フェーズで1動詞のみ解釈。
- 指を途中で離す→その位置から再開。巻き戻しなし。

## 成功の余韻

各スナップ/完了は最低1秒表示保持してから次フェーズへ。成功音+視覚一致(フラッシュ/波紋)は同一フレームで発火。

## seed

`seed` はURL `?seed=N` または再プレイメニューで決定。BeamShape(3種: 平行弦ガーダー / Xブレース格子パネル / 曲弦エッジ材)、作業員の服色、雲配置がseedに従い決定的。
