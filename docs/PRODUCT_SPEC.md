# ゾウのかくれごはん — 製品仕様

対象: 4歳児（主）＋親子（副）。iPhone/iPad Safari、縦横両対応、タッチ主体（マウスはQA fallback）。
1プレイ約3〜5分。文章を読めなくても映像・音・動きで進行できること。

沖縄こどもの国のアジアゾウ採食エンリッチメント（隠し餌・探索行動促進）に着想した**非公式・教育的**ゲーム。
公式素材は一切使用しない。情報画面に非公式である旨を明記する。

## 子ども文
「ごはんをいろいろな場所にかくして、ゾウさんに見つけてもらう。」

## ゲームループ（Acts）
1. **intro（朝の準備）**: 飼育員がカートで餌を運んでくる。文章説明なし。視線・指差し・揺れで誘導。
2. **hide（餌を隠す）**: ガイドプレイは3か所。餌をドラッグ→スポットへ吸着→スポット固有の仕上げ操作。
3. **gate（ゾウを迎える）**: ゲートレバーをスワイプ。扉が開きゾウがゆっくり登場。鼻を上げ匂いを探す短い探索。
4. **seek（5つの固有行動）**: 隠した各スポットでゾウが固有行動を実行。
   - A `probe-gap` 石垣の隙間へ鼻を差し込み、つまんで引き抜く
   - B `dig-sand` 砂を掘る。砂が退き餌が現れる
   - C `reach-pipe` 土管へ鼻を伸ばす。断面/半透明で内部を見せる
   - D `peel-banana` バナナ茎を一枚ずつ剥がす（ガジュマル根元）
   - E `break-branch` 高い枝を引いてしならせ、折って食べる
5. **album（おだやかな完成）**: 点数なし。その回に見た行動を絵カードで並べる。観察済み行動は端末に蓄積。
6. **replay**: 2タップ以内で再開。「もういちど」「ばしょをかえる」「じゆうにあそぶ」。初回完了後に自由遊び解放。

## スポットと餌の対応（データ駆動）
| spot | behavior | 受け入れ餌 | 隠す操作 |
|---|---|---|---|
| stone-gap | probe-gap | vegetable, hay-cube | 隙間へ押し込む |
| sand | dig-sand | vegetable, hay-cube | 置いて砂を左右からかぶせる（スワイプ） |
| pipe | reach-pipe | vegetable, hay-cube, grass | 奥へスワイプ |
| banyan-root | peel-banana | banana-stem | 根の奥へドラッグ |
| high-branch | break-branch | branch, grass | ロープへ掛けて上へ引き上げる |

ガイドプレイ（初回）は stone-gap / sand / high-branch の3か所（3系統の操作差を体験）。
2回目以降は毎回異なる組合せを提案。自由遊びでは最大5か所すべてに隠せる。

## 4歳児UX原則
- 一場面一動詞。主役は常に1つ。1指操作。制限時間・罰・ゲームオーバーなし。
- 広い吸着（スポット半径大）、軌道補正、タッチ目標64–96px相当。
- 3〜5秒無操作で非言語ヒント（飼育員の指差し、対象の微振動、局所光、短い音）。
- 成功の瞬間はカットせず、因果を一続きのカメラで見せ、余韻を残す。

## 再プレイ性
seed駆動の微差: 餌種、隠し場所提案、ゾウの初動方向、嗅ぎ時間、鼻軌道の揺らぎ、砂の崩れ、剥がれ方、探索順、朝/昼/夕の光。
`?seed=N` で完全再現。通常プレイは毎回変化。通貨・報酬・広告・収集ノルマは使わない。

## 禁止事項
点数/星/順位/時間評価、広告、analytics、ログイン、外部通信、公式素材の複製、絵文字を3D素材代わりに使うこと、紫グラデ中心の汎用AI風UI。

## 安全表現
子どもが直接ゾウへ給餌する描写はしない。飼育員の管理下で放飼場に餌を準備する、という枠組みで描く。
