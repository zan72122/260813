# VISUAL_DIRECTION

全体印象: 「上質な舞台模型と精巧なドールハウスの中間」。18世紀の私的な小劇場の親密さ。
写実3Dではなく、**意図的に平面装置（painted flats）らしい**手描き調。
正面からは奥行きのある世界に見え、横移動するとわずかに平面だと分かる——それが魅力。

## パレット

### 客席（Auditorium）— V2: 青・白・金
- 座席・壁布: 深い青 `#2e4a7d` 〜 淡青 `#7d95c4`
- 壁・柱: 温白 `#f3ede1`、偽大理石の淡い紫灰 `#b7aec2`
- 装飾: 控えめな金 `#c9a54e`（金色紙装飾。金属光沢は弱いsheenで、宝石粒子禁止）
- 光: 暖かい蝋燭・footlight `#ffd9a0`

### 地下（Understage）
- 古木: 蜂蜜色 `#c89b5a` 〜 焦茶 `#5a3d26`
- 麻ロープ: `#b8a074`
- 黒鉄金具: `#3a3733`
- 空気: 暖かい暗色、少量の粉塵billboard particle。真っ黒にしない（幼児が怖がらない暗さ）。

### 舞台装置三景
- Salon: 青灰壁 `#9aa8bd`、金縁 `#c9a54e`、絹椅子の淡い薔薇 `#d8a8a0`（ピンク一色禁止）
- Forest: 幹 `#6b5138`、葉の緑 `#5f7f4a`〜`#8faf6a`、木漏れ日 `#ffe9b8`
- Rustic: 漆喰 `#e8dcc4`、梁・家具の木 `#8a6a44`、暖炉の火色 `#e8934a`

## Hero Materials（最も磨く5つ）

1. **彩色キャンバス**: 布目ノイズ＋筆致風グラデ＋縁のわずかな色むら。手続き生成（canvas 2D→texture）。
2. **麻ロープ**: 撚り模様のtube。引くとUVスクロールで撚りが流れる。
3. **古い木**: ドラム・梁・滑車枠。木目手続きテクスチャ＋角の摩耗ハイライト。
4. **金色紙装飾**: 客席の縁取り。弱い環境反射＋高めのspecularで「紙に金箔」感。
5. **蝋燭光**: 暖色point/spotのごく緩い揺らぎ（Reduce Motion時は固定）。

## ライティング

- 客席側: 暖かい環境光＋footlights。影は原則1 caster（主無影＋接地フェイク影可）。
- 地下: 暗めの環境光＋ランタン風の局所暖光。ロープと歯止めが最も明るく読めること。
- 森完成時: 照明を室内色→緑がかった昼光へ progress でブレンド。木漏れ日はgobo texture。

## 禁止

- 現代的な黒い劇場設備、LEDスクリーン、金属トラス
- 画像一枚の単純フェード
- 汎用ファンタジー城、紫グラデーションUI、大量の角丸カード
- 著作権キャラクター、権利不明の実装置写真の取り込み
- 宝石粒子だけの豪華さ表現

## UI

文字なし。アイコンは絵として成立させる（手・ロープ・音符に斜線=mute等）。
UI色は客席パレットから取り、画面隅に小さく。主動作（ロープ）は必ず3D側で行い、DOMボタンで代替しない。
