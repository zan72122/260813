# VISUAL_DIRECTION — 視覚方向

到達点: **高品質な舞台模型と絵本の中間**。安価な子どもアプリ風平面アイコン集にしない。
完全写実の人物劇にも、汎用AIファンタジーにも寄せない。
「ミニチュアの庭園ジオラマに朝の光が当たっている」を基準イメージとする。

## パレット（基準値。シェーダ内での揺らぎは可）

| 用途 | 色 | 目安 |
|---|---|---|
| 刈込樹木の深緑 | `#2e5339` 〜 `#3d6b4a` | 生垣・トピアリー |
| ベルサイユ石材の温かい灰白 | `#d8d0c0` 〜 `#e8e2d4` | 石畳・縁石・彫像台座 |
| 金色彫像・太陽印 | `#c9a227` ハイライト `#f0d878` | 金箔調。過剰な発光禁止 |
| 真鍮 | `#a67c3d` | バルブ・レンチ |
| 緑青 | `#5e8f7a` | バルブの経年部 |
| 朝空の淡い青 | `#bcd4e6` → 地平 `#e8e0d0` | グラデーション背景 |
| 水 | 高透明。青緑 `#7fb8c4` を薄く、白い泡沫 | Hero Material 筆頭 |

## Hero Materials（描画予算をここへ集中）

1. **水**: 噴流 = 加算気味の半透明メッシュ＋particle 泡沫。配管内 = 発光する水塊シェーダ
2. **濡れる石**: 噴水稼働後、周囲石材の roughness を下げ暗く濡らす（時間で乾かなくてよい）
3. **金色 / 金箔調金属**: 彫像・太陽印。環境マップによる控えめな反射
4. **真鍮・緑青**: バルブ頭とレンチ。macro カメラに耐える法線・粗さ表現
5. **生垣**: 幾何学的刈込のシルエットが命。個葉は描かず、面の緑の質感で見せる

## 光

- 朝の低い斜光を主光源（影を落とすのはこれ1つ）＋淡い空色の環境光
- 過剰な bloom 禁止。水の輝きは形状と泡沫で作り、ポストは最小限
- 画面全体の高速点滅は禁止（Reveal の演出でも不可）

## 禁止事項

紫グラデーション主体 / 汎用ダッシュボード / 大量の角丸カード / 絵文字のアセット使用 /
システムフォント中心の管理画面風UI / 過剰bloom / 無関係な宝石・魔法杖・キャラクターIP模倣

## UI

- UI は最小限。絵アイコン（笛、矢印、リプレイ等）はコード生成の SVG/Canvas 描画
- 設定（mute / 光を弱く / Reduce Motion 追従）は隅の小さな絵アイコンから
- 文字を使う場合はタイトル画面のみ。ゲーム内指示に文字を使わない

## アセット方針

外部素材ゼロ。全ジオメトリはコード生成（Three.js プリミティブ＋Lathe/Tube/Extrude）、
全テクスチャは Canvas / シェーダで手続き生成、全音は Web Audio 合成。
public/generated/ に事前生成物を置く場合も生成スクリプトを scripts/ に残し、ASSET_MANIFEST.md に記録する。
