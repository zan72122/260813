# カメラとタイミング — ショット台本

プレイループをショット単位で固定する。座標・FOV・時間の正は
`docs/STYLE_LOCK.json`（camera.shots / timing）。ここでは**意図**を記す。

共通規則:

- 指が画面に触れている間、カメラは遷移中でも完全に静止する（`CameraRig.hold`）。
- 全遷移のeasingは sineInOut。
- 静止中のショットには呼吸（振幅 0.012 / 周期 6s）が乗る。reduced-motion時は 0。
- 縦画面は各ショットの `portraitPos/portraitTarget` を使う（再構図。トリミング禁止）。
- 回転（リサイズ）時は現在ショットへ 0.9s で滑らかに再構図する。進行状態は失われない。

---

## Shot 1 — Establish（導入）

| 項目 | 値 |
|---|---|
| カメラ | `establish`（後方やや上から全身） |
| 継続 | introHold = 2.6s + タイトル消灯 |
| 固定 | 操作不可の間のみ。触れられたら音のアンロックのみ行う |
| 同時に見せるもの | 少女の後ろ姿全体、髪の量感、夕暮れのドーム、光の粒 |

タイトル・ワードマークがゆっくり現れて消える。文章の説明は一切出さない。
遷移: `establish → braid` を 2.2s。

## Shot 2 — Action（編み込み: cross / drop / pick）

| 項目 | 値 |
|---|---|
| カメラ | `braid`（後方3/4。編みの弧と、滝が落ちる余白を同時にフレームに入れる） |
| 固定 | プレイヤー操作中は常に固定 |
| ヒント | 各動詞の初回は 0.9s 後、二回目以降は 5s 無操作で蛍が経路をなぞる |

- cross: 指ドラッグに髪が即時追従 → 閾値で 0.85s の編み込みアニメ（cubicOut）。
- drop: 1.35s の落下（重力 cubicOut ＋末尾の羽のようなwobble）。
- pick: 0.7s で新しい束が上から滑り込む（sineInOut）。

## Shot 3 — Material close-up（最初の滝だけ）

| 項目 | 値 |
|---|---|
| カメラ | `closeup`（編み口へ 2.8s かけてゆっくり寄る。カットしない） |
| タイミング | 最初の cross 完了直後に寄り始め、最初の pick 完了後 3.2s で `braid` へ戻る |
| 見せるもの | 束が滑る・締まる・落ちる接写。以降の drop/pick は既に理解済みなので引きで見せる |

## Shot 4 — Petal（編み目を花びらへ）

| 項目 | 値 |
|---|---|
| カメラ | `petal`（右側面。垂れた編み尾全体と頭の関係が読める） |
| 遷移 | 編み完了 → 2.2s |
| 操作 | ループを外へ引くと**同フレーム**で幅が変わる。プレイヤーごとの幅の差は保存する |
| 進行 | 5ループ中3ループが50%以上开いたら 0.7s 置いて次へ |

## Shot 5 — Coil top view(花へ巻く)

| 項目 | 値 |
|---|---|
| カメラ | `coil`(花の法線上から。螺旋の全周が見える"上面図") |
| 遷移 | 2.2s。以降、指の円運動が直接 coil 進行度になる(累積角 / (2π×2.5周)) |
| 完了 | 進行度1.0 → 0.8s の開花オーバーシュート → 宝石出現(backOut 0.8s) |

## Shot 6 — Gem(宝石ピン)

| 項目 | 値 |
|---|---|
| カメラ | `gem`(coilよりわずかに引き、花と宝石の浮遊位置を両方フレームに) |
| 期待 | 宝石は上で浮遊・呼吸(bob 1.6Hz)。近づくほど pulse が上がる |
| 吸着 | 中心から 0.09m 以内で磁着 0.4s(quartOut) |
| 差し込み | 0.55s(押し込み＋squash 18%) → 光の環 22粒 |
| 余韻 | 1.1s の減衰揺れ(花と宝石が同じwobbleを共有) |

## Shot 7 — Reveal(完成)

| 項目 | 値 |
|---|---|
| カメラ | `reveal` へ 6.0s の引き。滝の束と髪の花を同時にフレームへ |
| 余韻 | 引き完了後も何も出さない。計 7.2s 経過後に「もう一度」グリフが 1.4s でフェードイン |
| 動き | 少女の呼吸、落下束のシェーダー揺らぎ、宝石の内側の光、光の粒 — それぞれ周期を変える |

「もう一度」はタップで establish へ 1.6s → braid へ。リセットは即座、演出は静かに。

---

## カットを入れてはならない瞬間

- cross のドラッグ開始〜編み込み完了
- drop のスワイプ〜滝の着地
- coil の円運動中(進行度が動いている間)
- 宝石の磁着〜揺れの収束

これらの間にカメラを動かしたくなったら、動かすのではなく**次のショットの開始位置を見直す**こと。
